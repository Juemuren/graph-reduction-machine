# 核心 λ 编译器

编译器会把核心 λ 程序编译为 SKI 图。

编译器的模块划分见 [architecture.md#编译器](architecture.md#编译器)。

## 编译流程

编译的完整流程为：

1. 把核心 λ 展开为纯 λ
2. 对纯 λ 进行归约
3. 把归约后的纯 λ 翻译为 SKI 图

在展开为纯 λ 后，编译器会检查表达式，并拒绝含自由变量的表达式。

### 名称和字面量展开

对于名称的展开：

- 名称在展开时被替换为名称的定义
- 如果名称引用其它名称，则展开时会递归替换

对于字面量的展开：

- 十进制自然数字面量被替换为对应的数字编码，提供 Church 编码和 Scott 编码

### 表达式归约

编译器默认不进行表达式归约，直接进行表达式翻译。

归约需要指定启用的归约类型。纯 λ 表达式归约包含 β 归约和 η 归约，可以同时启用：

- β 归约将 `(\x -> t) u` 替换为 `t[x := u]`，替换时避免变量捕获，并优先归约最外层应用
- η 归约将 `\x -> f x` 替换为 `f`，前提是 `x` 不在 `f` 中自由出现

归约时会不断检查表达式，直到无法继续归约。

### 表达式翻译

对于 `\x -> t` 表达式，按照翻译规则转换为 SKI 组合子：

- 若 `t` 不含 `x`，转换为 `K t`
- 若 `t` 就是 `x`，转换为 `I`
- 若 `t` 是应用 `u v`，转换为 `S (\x -> u) (\x -> v)`，并继续消去其中的抽象

对 λ 抽象的消去会逐层进行。

最终组合子及其应用被写成以 `#0` 为根的 SKI 图。

## 编译器选项

在指定阶段后停止编译：

- 使用 `--stop-after=expand` 参数时，在定义展开后停止
- 使用 `--stop-after=reduce` 参数时，在表达式归约后停止

指定启用的归约类型：

- 使用 `--enable-reduce=beta` 启用 β 归约
- 使用 `--enable-reduce=eta` 启用 η 归约
- 使用 `--enable-reduce=both` 启用 β 归约和 η 归约

指定字面量的编码：

- 使用 `--encode=church` 选择 Church 编码
- 使用 `--encode=scott` 选择 Scott 编码
