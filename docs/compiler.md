# 核心 λ 编译器

编译器会把核心 λ 程序编译为 SKI 图。

编译器的模块划分见 [architecture.md#编译器](architecture.md#编译器)。

## 编译流程

编译的完整流程为：

1. 把核心 λ 展开为纯 λ
2. 检查展开后的纯 λ 表达式，如果含自由变量则拒绝编译
3. 对纯 λ 进行归约
4. 把归约后的纯 λ 翻译为 SKI 图

### 展开

展开阶段的处理顺序为：

1. 加载导入模块。解析输入文件后，按导入路径递归读取并解析依赖的模块
2. 确定程序入口。从解析结果中取出入口表达式
3. 校验入口模块的导入。确认导入名没有冲突，并且所请求的名称由目标模块导出
4. 递归展开表达式
   - 对于应用，先展开函数，再展开参数；对于 λ 抽象，在加入新的绑定后展开函数体
   - 定义替换和字面量编码在递归展开时随着遍历交替进行：遇到字面量就编码为表达式，遇到定义就递归替换为定义体
   - 导入检查会随着递归展开而持续进行

#### 定义替换

λ 绑定的普通变量保留原样。其余名称先查本地定义，再查显式导入；都找不到时，普通名称保留为自由变量，内置名称继续查标准库。

找到定义后，名称被替换为定义体；如果定义引用其它定义，则会递归替换。

展开阶段只会替换从入口直接或间接引用到的定义，并且会检查循环引用和自由变量：

- 进入定义前，如果该定义已在当前展开链上，则报告循环引用
- 定义体展开后，检查该展开后的定义体是否含有自由变量：如果有自由变量，则报告自由变量；如果没有自由变量，则用展开后的定义体替换引用

#### 字面量编码

- 遇到自然数字面量时，按选定编码生成纯 λ 表达式。具体表示见 [lib.md#自然数](lib.md#自然数)
- 遇到字符串字面量时，按选定的自然数编码转换各字符的 Unicode 码点，再按选定的列表编码组成字符串。具体表示见 [lib.md#字符串](lib.md#字符串)

### 表达式归约

编译器默认不进行表达式归约。

归约需要指定启用的归约规则。纯 λ 表达式归约包含 β 归约和 η 归约，可以同时启用：

- β 归约将 `(\x -> t) u` 替换为 `t[x := u]`，替换时避免变量捕获，并优先归约最外层应用
- η 归约将 `\x -> f x` 替换为 `f`，前提是 `x` 不在 `f` 中自由出现

归约时会不断检查表达式，直到无法继续归约。

### 翻译

对于 `\x -> t` 表达式，按照翻译规则转换为 SKI 组合子：

- 若 `t` 不含 `x`，转换为 `K t`
- 若 `t` 就是 `x`，转换为 `I`
- 若 `t` 是应用 `u v`，转换为 `S (\x -> u) (\x -> v)`，并继续消去其中的抽象

对 λ 抽象的消去会逐层进行。

最终组合子及其应用被写成以 `#0` 为根的 SKI 图。

## 编译器选项

在指定阶段后停止编译：

- 使用 `--stop-after=expand` 参数时，在定义和字面量展开后停止，输出得到的纯 λ 表达式
- 使用 `--stop-after=reduce` 参数时，在表达式归约后停止

指定启用的归约规则：

- 使用 `--enable-reduce=beta` 启用 β 归约
- 使用 `--enable-reduce=eta` 启用 η 归约
- 使用 `--enable-reduce=both` 启用 β 归约和 η 归约

指定字面量的编码：

- 使用 `--encode-natural=church|scott|binary` 指定自然数字面量的编码，默认为 `church`
- 使用 `--encode-string=L<N>` 指定字符串字面量的编码，其中 `L` 表示有序列表编码，可以是 `church` / `scott`；`N` 表示自然数编码，可以是 `church` / `scott` / `binary`，默认为 `church<binary>`
