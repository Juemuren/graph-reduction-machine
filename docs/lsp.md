# 语言服务器

## 架构

语言服务器分为两个部分：

- 核心 λ 的语言服务器
- SKI 图的语言服务器

两部分包含于同一个可执行文件中。

语言服务器的模块划分见 [architecture.md#语言服务器](architecture.md#语言服务器)。

语言服务的实现使用 Haskell `lsp` 库。

## 功能

### 核心 λ

语言 ID 为 `core-lambda`。

#### 核心 λ 的语义高亮

用于区分一个名称是定义还是参数。

参数会遮蔽同名定义。

#### 核心 λ 的补全

补全支持：

- 可见的本地定义
- 导入名称
- 当前位置作用域内的函数参数

补全项区分参数与定义：

- 对于参数，命名函数的参数显示所属函数，匿名函数的参数只显示参数
- 对于定义，补全项的简略信息为所有参数，详细信息为完整定义

暂不支持补全内置函数，也不支持导入中的相对路径补全。

#### 核心 λ 的悬停

悬停支持显示定义和参数的信息：

- 对于参数，显示定义的行号
- 对于本地名称，显示完整的定义和定义的行号
- 对于导入名称，会显示导入文件的路径，并尝试读取对应文件的导出信息。目标文件无法读取时保留本地可得的信息

#### 核心 λ 的导航

支持跳转到定义、查找引用和文档符号：

- 跳转到定义可定位当前文件中的定义和参数，导入名称会跳转到对应文件中的导出定义
- 查找引用在当前文档内按绑定关系查找
- 文档符号列出当前文件中的本地定义和导出定义

#### 核心 λ 的重构

支持对定义进行重命名：

- 本地名称和参数支持重命名
- 导入名称不支持重命名

#### 核心 λ 的诊断

诊断包含：

- 语法错误
- 重复名称
- 表达式中未定义小写字母开头的名称

暂不包含对内置函数的诊断。

### SKI 图

语言 ID 为 `ski-graph`。

#### SKI 图的补全

支持节点的补全：

- 在节点引用位置输入 `#` 会自动触发补全
- 补全项为当前文件中已定义的节点编号
- 补全项的信息为节点的定义

#### SKI 图的悬停

悬停在节点引用处时显示该节点的定义。

#### SKI 图的导航

支持跳转到定义、查找引用和文档符号。

#### SKI 图的重构

支持重命名操作：

- 重命名会同时修改节点定义及所有边引用
- 目标编号必须为 `#` 接上十进制数字，且不得与现有节点编号重复
- 根节点 `#0` 不可重命名

#### SKI 图的诊断

诊断包含：

- 语法错误
- 重复节点
- 未定义节点
- 缺少根节点 `#0`

## 测试

端到端测试用 `lsp-test` 驱动真实服务进程。

包含文档打开与文档修改后的请求：

- 对于核心 λ 测试补全、悬停、作用域、导入、注释、诊断、导航、重构
- 对于 SKI 图测试补全、悬停、注释、诊断、导航、重构
