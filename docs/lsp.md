# 语言服务器

## 架构

语言服务器分为两个部分：

- 核心 λ 的语言服务器
- SKI 图的语言服务器

两部分包含于同一个可执行文件中。

语言服务器的模块划分见 [architecture.md#语言服务器](architecture.md#语言服务器)。

语言服务的实现使用 Haskell `lsp` 库。

## 功能

### 核心 λ

语言 ID 为 `core-lambda`。

#### 核心 λ 的语义高亮

用于区分一个名称是定义还是参数。

参数会遮蔽同名定义。

#### 核心 λ 的补全

补全支持可见的本地定义、导入名称，以及当前位置作用域内的函数参数。

候选名称会被去重。

暂不支持补全内置函数，也不支持导入中的相对路径补全。

#### 核心 λ 的悬停

悬停支持显示定义和参数的信息。

对于导入的定义，会读取相对路径对应的文件，并查找其中导出的定义。目标文件无法读取时保留本地可得的信息。

悬停返回的内容为 Markdown 格式。

### SKI 图

语言 ID 为 `ski-graph`。

#### SKI 图的补全

在节点引用位置补全当前文件中已定义的节点编号。

#### SKI 图的悬停

悬停在节点引用处时显示该节点的定义。

## 测试

端到端测试用 `lsp-test` 驱动真实服务进程。

包含文档打开与文档修改后的请求：

- 对于核心 λ 测试补全、悬停、作用域、导入、注释及不完整源码
- 对于 SKI 图测试补全、悬停、注释及不完整源码
