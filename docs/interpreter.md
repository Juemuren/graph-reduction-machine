# SKI 图解释器

解释器会对 SKI 图进行解释。

解释器的模块划分见 [architecture.md#解释器](architecture.md#解释器)。

## 解释流程

解释器根据是否指定解码方式存在不同流程：

- 未指定解码方式时：
   1. 对 SKI 图进行归约
   2. 输出归约后的 SKI 图
- 指定解码方式时：
   1. 根据解码方式按需归约 SKI 图，并检查编码结构
   2. 输出解码得到的值

### 图归约

图归约的步骤为：

1. 从根节点 `#0` 开始，按规则改写节点：
   - `I x` 改写为 `x`
   - `K x y` 改写为 `x`
   - `S x y z` 改写为 `(x z) (y z)`
2. 继续归约该节点，然后递归归约节点的边；若归约后产生新的可归约应用，则继续改写
3. 当根节点可达的图中没有可归约应用时，输出最终的 SKI 图

每次组合子改写计为一步。

归约存在步数限制。默认的步数限制为 `100000`。超过步数上限时会报错。

### 解码

解释器默认不尝试解码，只输出归约后 SKI 图。

解码需要指定解码方式。解码成功后输出对应的值，解码失败时报错。

解码方式不能同时使用，因为相同编码在不同解码方式下的结果可能不同。比如布尔值 `FALSE` 与自然数 `0` 的编码相同，但自然数解码得到 `0`，布尔值解码得到 `FALSE`。

解码中的归约也存在步数限制。超过步数上限时会报错。

#### 布尔值解码

使用布尔值解码时，解释器会把输入图的根表达式应用到符号参数 `a` 和 `b`，再归约所得表达式：

- 若归约结果为 `a` 则解码得到 `TRUE`
- 若归约结果为 `b` 则解码得到 `FALSE`
- 若归约结果不符合以上两种形式，则解码失败

#### 自然数解码

使用 Church 自然数解码时，解释器会把输入图的根表达式应用到符号参数 `f` 和 `x`，再归约所得表达式：

- 若归约结果为 `x` 则解码得到 `0`
- 若归约结果为 `f x` 则解码得到 `1`
- 若归约结果为 `f (f x)` 则解码得到 `2`
- 以此类推，若归约结果为 `f` 对 `x` 重复作用，则重复作用的次数就是解码得到的 Church 自然数
- 若归约结果不符合这种形式，则解码失败

使用 Scott 自然数解码时，解释器会把输入图的根表达式应用到符号参数 `z` 和 `s`，再归约所得表达式：

- 若归约结果为 `z` 则解码得到 `0`
- 若归约结果为 `s n`，则按 Scott 自然数递归解码 `n`
   - 若 `n` 解码成功，则把 `n + 1` 作为解码得到 Scott 自然数
   - 若 `n` 解码失败，则 Scott 自然数解码失败
- 若归约结果不符合以上两种形式，则解码失败

#### 整数解码

使用整数解码时，解释器会把输入图的根表达式应用到符号参数 `f`，再将表达式归约到 `f a b` 形式，然后分别按 Church 自然数解码 `a` 和 `b`：

- 若 `a` 和 `b` 解码成功，则把 `a - b` 的结果作为解码得到的整数
- 若 `a` 或 `b` 解码失败，则整数解码失败

#### 有理数解码

使用有理数解码时，解释器会把输入图的根表达式应用到符号参数 `f`，再将表达式归约到 `f a b` 形式，然后分别按整数解码 `a` 和 `b`：

- 若 `a` 和 `b` 解码成功，则把 `a / b` 约分后的结果作为解码得到的有理数
- 若 `a` 或 `b` 解码失败，则有理数解码失败

#### 实数解码

使用实数解码时，解释器会把输入图的根表达式应用到指定的自然数下标 `n`，再将所得表达式 `a` 按有理数解码：

- 若 `a` 解码成功，则把有理数 `a` 作为解码得到的实数近似值
- 若 `a` 解码失败，则实数解码失败

默认的自然数下标为 `0`。

## 解释器选项

指定归约的步数上限：

- 用 `--max-steps=N` 指定步数上限为正整数 `N`
- 用 `--no-step-limit` 禁用步数上限。不能和 `--max-steps=N` 同时使用
- 用 `--show-steps` 在成功输出结果后，将实际的归约步数写入标准错误。格式为 `steps: N`

指定解码方式：

- 用 `--decode=boolean` 解码布尔值
- 用 `--decode=natural` 解码 Church 自然数
- 用 `--decode=scott-natural` 解码 Scott 自然数
- 用 `--decode=integer` 解码整数
- 用 `--decode=rational` 解码有理数
- 用 `--decode=real` 解码实数，用 `--precision-real=N` 指定解码时使用的自然数下标为 `N`
