# SKI 图解释器

解释器会对 SKI 图进行解释。

解释器的模块划分见 [architecture.md#解释器](architecture.md#解释器)。

## 解释流程

解释器根据是否指定解码方式存在不同流程：

- 未指定解码方式时：
   1. 对 SKI 图进行归约
   2. 输出归约后的 SKI 图
- 指定解码方式时：
   1. 根据解码方式按需归约 SKI 图，并检查编码结构
   2. 输出解码得到的值

### 图归约

图归约的步骤为：

1. 从根节点 `#0` 开始，按规则改写节点：
   - `I x` 改写为 `x`
   - `K x y` 改写为 `x`
   - `S x y z` 改写为 `(x z) (y z)`
2. 继续归约该节点，然后递归归约节点的边；若归约后产生新的可归约应用，则继续改写
3. 当根节点可达的图中没有可归约应用时，输出最终的 SKI 图

每次组合子改写计为一步。

归约存在步数限制。超过步数上限时会报错。

### 解码

解释器默认不尝试解码，只输出归约后 SKI 图。

解码需要指定解码方式。解码成功后输出对应的值，解码失败时报错。

解码方式不能同时使用，因为相同编码在不同解码方式下的结果可能不同。比如布尔值 `FALSE` 与自然数 `0` 的编码相同，但自然数解码得到 `0`，布尔值解码得到 `FALSE`。

解码中的归约也存在步数限制。超过步数上限时会报错。

#### 布尔值解码

使用布尔值解码时，解释器会把输入图的根表达式应用到符号参数 `a` 和 `b`，再归约所得表达式：

- 若归约结果为 `a` 则解码得到 `TRUE`
- 若归约结果为 `b` 则解码得到 `FALSE`
- 若归约结果不符合以上两种形式，则解码失败

#### 自然数解码

使用 Church 自然数解码时，解释器会把输入图的根表达式应用到符号参数 `f` 和 `x`，再归约所得表达式：

- 若归约结果为 `x` 则解码得到 `0`
- 若归约结果为 `f x` 则解码得到 `1`
- 若归约结果为 `f (f x)` 则解码得到 `2`
- 以此类推，若归约结果为 `f` 对 `x` 重复作用，则重复作用的次数就是解码得到的 Church 自然数
- 若归约结果不符合这种形式，则解码失败

使用 Scott 自然数解码时，解释器会把输入图的根表达式应用到符号参数 `z` 和 `s`，再归约所得表达式：

- 若归约结果为 `z` 则解码得到 `0`
- 若归约结果为 `s n`，则按 Scott 自然数递归解码 `n`
   - 若 `n` 解码成功，则把 `n + 1` 作为解码得到 Scott 自然数
   - 若 `n` 解码失败，则 Scott 自然数解码失败
- 若归约结果不符合以上两种形式，则解码失败

使用 Binary 自然数解码时，解释器把根表达式应用到符号参数 `z`、`e` 和 `o`，再归约所得表达式：

- 若归约结果为 `z`，则解码得到 `0`
- 若归约结果为 `e n`，则按 Binary 自然数递归解码 `n`
   - 若 `n` 解码成功，则把 `2n` 作为解码得到 Binary 自然数
   - 若 `n` 解码失败，则 Binary 自然数解码失败
- 若归约结果为 `o n`，则按 Binary 自然数递归解码 `n`
   - 若 `n` 解码成功，则把 `2n+1` 作为解码得到 Binary 自然数
   - 若 `n` 解码失败，则 Binary 自然数解码失败
- 若归约结果不符合以上三种形式，则解码失败

#### 整数解码

使用整数解码时，解释器会把输入图的根表达式应用到符号参数 `f`，再将表达式归约到 `f a b` 形式，然后分别按 Church 自然数解码 `a` 和 `b`：

- 若 `a` 和 `b` 解码成功，则把 `a - b` 的结果作为解码得到的整数
- 若 `a` 或 `b` 解码失败，则整数解码失败

#### 有理数解码

使用有理数解码时，解释器会把输入图的根表达式应用到符号参数 `f`，再将表达式归约到 `f a b` 形式，然后分别按整数解码 `a` 和 `b`：

- 若 `a` 和 `b` 解码成功，则把 `a / b` 约分后的结果作为解码得到的有理数
- 若 `a` 或 `b` 解码失败，则有理数解码失败

#### 实数解码

使用实数解码时，解释器会把输入图的根表达式应用到指定的自然数下标 `n`，再将所得表达式 `a` 按有理数解码：

- 若 `a` 解码成功，则把有理数 `a` 作为解码得到的实数近似值
- 若 `a` 解码失败，则实数解码失败

默认的自然数下标为 `0`。

#### 字符串解码

使用字符串 `L<N>` 解码时，解释器按有序列表 `L` 的解码方式解码有序列表，按自然数 `N` 的解码方式解码自然数。

解释器会把输入图的根表达式应用到符号参数 `c` 和 `n`，再归约所得表达式：

- 若归约结果为 `n`，则把 `""` 作为解码得到的字符串
- 若归约结果为 `c a r`，则按 `N` 的解码方式解码 `a`，按 `L<N>` 的解码方式递归解码 `r`
   - 若 `a` 和 `r` 解码成功，则把 `a` 对应的字符放在 `r` 的开头，作为解码得到的字符串
   - 若 `a` 或 `r` 解码失败，则字符串解码失败
- 若结果不符合以上两种形式，则字符串解码失败

字符的有效 Unicode 标量值范围是从 `0` 至 `0x10FFFF` 且排除从 `0xD800` 至 `0xDFFF` 的代理项。超出此范围的自然数会视作字符串解码失败。

#### 有序对解码

使用有序对 `pair<A,B>` 解码时，解释器会把输入图的根表达式应用到符号参数 `f`，再将所得表达式归约到 `f a b` 形式，然后分别按 `A` 和 `B` 的解码方式解码 `a` 和 `b`：

- 若 `a` 和 `b` 解码成功，则把 `(a, b)` 作为解码得到的有序对
- 若 `a` 或 `b` 解码失败，则有序对解码失败

#### 有序列表解码

使用 Church 有序列表 `list<T>` 解码时，解释器会把输入图的根表达式应用到符号参数 `c` 和 `n`，再归约所得表达式：

- 若归约结果为 `n`，则把 `[]` 作为解码得到的有序列表
- 若归约结果为 `c a r`，则按 `T` 的解码方式解码 `a`，按 `list<T>` 的解码方式递归解码 `r`
   - 若 `a` 和 `r` 解码成功，则把 `a` 放在列表 `r` 的开头，作为解码得到的 Church 有序列表
   - 若 `a` 或 `r` 解码失败，则 Church 有序列表解码失败
- 若结果不符合以上两种形式，则 Church 有序列表解码失败

使用 Scott 有序列表 `scott-list<T>` 解码时，解释器会把输入图的根表达式应用到符号参数 `c` 和 `n`，再归约所得表达式：

- 若归约结果为 `n`，则把 `[]` 作为解码得到的有序列表
- 若归约结果为 `c a r`，则按 `T` 的解码方式解码 `a`，按 `scott-list<T>` 的解码方式递归解码 `r`
   - 若 `a` 和 `r` 解码成功，则把 `a` 放在列表 `r` 的开头，作为解码得到的 Scott 有序列表
   - 若 `a` 或 `r` 解码失败，则 Scott 有序列表解码失败
- 若结果不符合以上两种形式，则 Scott 有序列表解码失败

## 解释器选项

指定归约的步数上限：

- 用 `--max-steps=N` 指定步数上限为正整数 `N`，默认为 `100000`
- 用 `--no-step-limit` 禁用步数上限。不能和 `--max-steps=N` 同时使用

显示归约的步数上限：

- 用 `--show-steps` 在成功输出结果后，显示实际的归约步数。默认不开启。归约步数会写入标准错误，格式为 `steps: N`

指定输出图的共享方式：

- 用 `--share=preserve` 保留输入图已有的共享节点和归约过程中产生的共享节点，为默认方式
- 用 `--share=merge` 在归约完成后，合并结构相同的节点。不影响归约步数
- 用 `--share=unfold` 在归约完成后，将共享节点展开为独立节点，使输出图变成一棵二叉树。不影响归约步数，但图可能显著变大
- `--share` 只用于图输出，不能与 `--decode` 同时使用

指定解码方式：

- 用 `--decode=boolean` 解码布尔值
- 用 `--decode=natural` 解码 Church 自然数
- 用 `--decode=scott-natural` 解码 Scott 自然数
- 用 `--decode=binary-natural` 解码二进制自然数
- 用 `--decode=integer` 解码整数
- 用 `--decode=rational` 解码有理数
- 用 `--decode=real` 解码实数，用 `--precision-real=N` 指定解码时使用的自然数下标为 `N`
- 用 `--decode=string` 解码用 Church 列表和 Binary 自然数表示的字符串，等价于 `--decode=string<church<binary>>`
- 用 `--decode=string<L<N>>` 解码用 `L` 列表和 `N` 自然数表示的字符串，其中 `L` 可以是 `church` / `scott`，`N` 可以是 `church` / `scott` / `binary`
- 用 `--decode=list<T>` 解码 Church 列表
- 用 `--decode=scott-list<T>` 解码 Scott 列表
- 用 `--decode=pair<A,B>` 解码 Church 有序对
- `--decode` 不能与 `--share` 同时使用

其中 `T`、`A`、`B` 可以是 `natural` / `scott-natural` / `binary-natural` / `boolean` / `integer` / `rational` / `string` / `string<L<N>>`，也可以是嵌套的 `list<T>` / `scott-list<T>` / `pair<A,B>`；`real` 目前不能用于复合类型。
