# SKI 图解释器

解释器会对 SKI 图进行解释。

解释器的模块划分见 [architecture.md#解释器](architecture.md#解释器)。

## 解释流程

解释的完整流程为：

1. 对 SKI 图进行归约
2. 对归约后的 SKI 图进行解码

### 图归约

图归约的步骤为：

1. 从根节点 `#0` 开始，按规则改写节点：
   - `I x` 改写为 `x`
   - `K x y` 改写为 `x`
   - `S x y z` 改写为 `(x z) (y z)`
2. 继续归约该节点，然后递归归约节点的边；若归约后产生新的可归约应用，则继续改写
3. 当根节点可达的图中没有可归约应用时，输出最终的 SKI 图

每次组合子改写计为一步。

归约存在步数限制。默认的步数限制为 `100000`。超过步数上限时会报错。

### 解码

解释器默认不尝试解码，只输出归约后 SKI 图。

解码需要指定解码方式。解码成功后输出对应的值，解码失败时报错。

解码方式不能同时使用，因为相同编码在不同解码方式下的结果可能不同。比如布尔值 `FALSE` 与自然数 `0` 的编码相同，但自然数解码得到 `0`，布尔值解码得到 `FALSE`。

解码也存在步数限制。超过步数上限时会报错。

#### 布尔值解码

使用布尔值解码时，解释器会把结果应用到符号参数 `a` 和 `b`：

- 若返回的是 `a` 则解码得到 `TRUE`
- 若返回的是 `b` 则解码得到 `FALSE`

#### 自然数解码

使用自然数解码时，解释器会把结果应用到符号参数 `f` 和 `x`：

- 若归约结果为 `x` 则解码得到 `0`
- 若归约结果为 `f x` 则解码得到 `1`
- 若归约结果为 `f (f x)` 则解码得到 `2`
- 以此类推，`f` 对 `x` 重复作用的次数就是解码得到的自然数

#### 整数解码

使用整数解码时，解释器会把结果应用到符号参数 `f`：

- 若归约结果为 `f a b`，则分别按自然数解码 `a` 和 `b`
- 若两个自然数都解码成功，则把 `a - b` 的结果作为解码得到的整数
- 若存在自然数解码失败，则整数解码失败

#### 有理数解码

使用有理数解码时，解释器会把结果应用到符号参数 `f`：

- 若归约结果为 `f a b`，则分别按整数解码 `a` 和 `b`
- 若两个整数都解码成功，则把 `a / b` 约分后的结果作为解码得到的有理数
- 若存在整数解码失败，则有理数解码失败

#### 实数解码

使用实数数解码时，解释器会把结果应用到指定的自然数下标 `n`，并对归约结果 `a` 按有理数解码：

- 若有理数解码成功，则把 `a` 作为解码得到的实数
- 若有理数解码失败，则实数解码失败

默认的自然数下标为 `0`。

## 解释器选项

指定步数上限：

- 用 `--max-step=N` 指定步数上限

指定解码方式：

- 用 `--decode=boolean` 解码布尔值
- 用 `--decode=natural` 解码自然数
- 用 `--decode=integer` 解码整数
- 用 `--decode=rational` 解码有理数
- 用 `--decode=real` 解码实数，用 `--precision-real=N` 指定解码时使用的自然数下标
