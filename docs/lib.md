# 标准库

核心 λ 标准库的所有内置函数都在项目的 `lib/` 目录中定义和导出。

## 组合子

组合子的实现位于 [combinator.lambda](../lib/combinator.lambda)。

### 基本组合子

- `I x` 返回 `x`，是恒等组合子
- `K x y` 返回 `x`，忽略第二个参数
- `S f g x` 返回 `f x (g x)`，将 `x` 同时传给 `f` 和 `g`

### 函数操作组合子

- `B f g x` 返回 `f (g x)`，将 `g` 的结果传给 `f`
- `C f x y` 返回 `f y x`，交换后两个参数
- `W f x` 返回 `f x x`，将参数 `x` 传入两次
- `M f` 返回 `f f`，将函数应用于自身
- `T x f` 返回 `f x`，先给出参数，再给出函数
- `V x y f` 返回 `f x y`，先给出两个参数，再给出函数
- `D f g h x` 返回 `f (g (h x))`，依次应用 `h`、`g` 和 `f`

### 不动点组合子

- `Y f` 满足 `Y f = f (Y f)`，适合非严格求值的递归
- `Z f` 满足 `Z f = f (Z f)`，适合严格求值的递归
- `A x f` 返回 `f (x x f)`，用于构造 `THETA`
- `THETA f` 满足 `THETA f = f (THETA f)`，适合非严格求值的递归，且展开速度通常比 `Y` 更快

## 高阶函数

高阶函数的实现位于 [higher-order.lambda](../lib/higher-order.lambda)。

- `ID x` 返回 `x`
- `COMPOSE f g x` 返回 `f (g x)`，表示函数复合
- `CONST x y` 返回 `x`，可用于构造常值函数
- `FLIP f x y` 返回 `f y x`，交换二元函数的参数顺序
- `CURRY f x y` 返回 `f (PAIR x y)`，将接收有序对的函数改为逐个接收参数
- `UNCURRY f p` 返回 `f (FST p) (SND p)`，将二元函数改为接收有序对

## 控制

控制的实现位于 [control.lambda](../lib/control.lambda)。

### 条件

- `IF b t f` 当 `b` 为真值时选择 `t`，当 `b` 为假值时选择 `f`

### 递归

- `FIX f` 表示函数 `f` 的不动点，可用于定义递归函数。当前实现采用 `Y` 组合子

### 循环

- `FOR n s i` 从 `i` 作为初始状态，执行 `s` 共 `n` 次，输出最终状态
- `WHILE c s i` 从 `i` 作为初始状态，当 `c` 对当前状态返回真值时执行 `s`，当 `c` 对当前状态返回假值时输出最终状态

## 布尔值

布尔值的实现位于 [boolean.lambda](../lib/boolean.lambda)。

### 布尔值构造

- `FALSE` 表示假值
- `TRUE` 表示真值

### 布尔值运算

- `AND a b` 表示布尔值 `a` 和布尔值 `b` 的与运算
- `OR a b` 表示布尔值 `a` 和布尔值 `b` 或运算
- `NOT a` 表示布尔值 `a` 的非运算

## 有序对

有序对的实现位于 [pairs.lambda](../lib/pairs.lambda)。

### 有序对构造

- `PAIR a b` 构造第一个分量为 `a`、第二个分量为 `b` 的有序对

### 有序对操作

有序对的解构：

- `FST p` 获取有序对 `p` 的第一个分量
- `SND p` 获取有序对 `p` 的第二个分量

## 有序列表

有序列表的实现位于 [list.lambda](../lib/list.lambda)。

目前提供两种有序列表的编码方式：

- Church 列表编码，其相关的内置函数都无后缀。操作函数的列表参数与列表结果均使用 Church 列表编码，列表索引和列表度量均使用 Church 自然数编码
- Scott 列表编码，其相关的内置函数都添加 `_S` 后缀。操作函数的列表参数与列表结果均使用 Scott 列表编码，列表索引和列表度量均使用 Scott 自然数编码

两种列表编码不可混用，且需要不同的解码方式，详见 [interpreter.md#解释器选项](interpreter.md#解释器选项)。

### 有序列表构造

- `NIL` 表示空列表
- `CONS a l` 表示将元素 `a` 放在列表 `l` 开头的新列表

### 有序列表操作

有序列表的遍历：

- `FOLDR f i l` 从右向左折叠列表 `l`，即 `f` 依次接收当前元素和已折叠的结果，`i` 是空列表的返回值；若 `l` 为 `[a_1, a_2, ..., a_n]`，则返回 `f a_1 (f a_2 (... (f a_n i)))`
- `FOLDL f i l` 从左向右折叠列表 `l`，即 `f` 依次接收已折叠的结果和当前元素，`i` 是空列表的返回值；若 `l` 为 `[a_1, a_2, ..., a_n]`，则返回 `f (... (f (f i a_1) a_2) ...) a_n`

有序列表的变换：

- `MAP f l` 对列表 `l` 的每个元素应用 `f`，返回保持原有顺序的新列表
- `FILTER p l` 返回列表 `l` 中所有使 `p` 返回 `TRUE` 的元素组成的、保持原有顺序的新列表
- `REVERSE l` 返回列表 `l` 的元素按相反顺序组成的新列表
- `INSERT i x l` 返回列表 `l` 索引 `i` 处插入元素 `x` 后得到的新列表。索引 `i` 从零开始计数
- `SORT p l` 返回列表 `l` 按二元比较运算 `p` 排序后的新列表。对新列表的所有相邻元素，若 `a` 在前 `b` 在后，则 `p a b` 返回 `TRUE`

有序列表的解构：

- `HEAD d l` 返回列表 `l` 的首元素；当 `l` 为空列表时返回 `d`
- `TAIL l` 返回列表 `l` 去掉首元素后的新列表；当 `l` 为空列表时返回 `NIL`
- `INDEX i d l` 返回列表 `l` 的第 `i` 个元素，若越界则返回 `d`。索引 `i` 从零开始计数
- `FIND p d l` 返回列表 `l` 从左到右第一个满足 `p` 的元素，若没有匹配则返回 `d`
- `TAKE n l` 返回由列表 `l` 开头最多 `n` 个元素组成的、保持原有顺序的新列表；当 `l` 为空列表时返回 `NIL`
- `DROP n l` 返回列表 `l` 去除开头最多 `n` 个元素后得到的、保持原有顺序的新列表；当 `l` 为空列表时返回 `NIL`
- `UNCONS l` 返回解构列表后得到的有序对，其中第一个分量是列表 `l` 的首元素，第二个分量是列表 `l` 去掉首元素后的新列表；当 `l` 为空列表时返回 `PAIR NIL NIL`
- `CASE l n c` 对列表进行模式匹配。如果列表 `l` 为空列表，则返回 `n`；如果列表 `l` 不为空列表，则返回 `c (HEAD NIL l) (TAIL l)`

有序列表的组合：

- `APPEND a b` 返回依次包含列表 `a` 的全部元素和列表 `b` 的全部元素的新列表
- `CONCAT ll` 展平列表的列表 `ll`，即依次取出 `ll` 中的每个列表中的每个元素组成新列表；若 `ll` 为 `[[a_1, ..., a_m], [b_1, ..., b_n], ..., [h_1, ..., h_r]]`，则返回 `[a_1, ..., a_m, b_1, ..., b_n, h_1, ..., h_r]`

有序列表的度量：

- `LENGTH l` 返回列表 `l` 的元素个数

有序列表的比较：

- `ISNIL l` 判断列表 `l` 是否为空；空列表返回 `TRUE`，非空列表返回 `FALSE`

## 自然数

自然数的实现位于 [natural.lambda](../lib/natural.lambda)。

自然数使用皮亚诺公理进行定义。`ZERO` 对应数值 $0$，`SUCC` 是后继构造子，`SUCC n` 对应数值 $n+1$。

一是零的后继

```lambda
SUCC ZERO
```

二是一的后继

```lambda
SUCC (SUCC ZERO)
```

以此类推。

皮亚诺公理可以认为是一种一进制数字，因此数值为 $n$ 的数字需要 $O(n)$ 的表示长度。

二进制使用两种构造子，分别为偶构造子 `EVEN` 和奇构造子 `ODD`，`EVEN n` 和 `ODD n` 分别对应数值 $2n$ 和 $2n+1$。

一是零的奇构造

```lambda
ODD ZERO
```

二是一的偶构造

```lambda
EVEN (ODD ZERO)
```

三是一的奇构造

```lambda
ODD (ODD ZERO)
```

四是二的偶构造

```lambda
EVEN (EVEN (ODD ZERO))
```

以此类推。

数值为 $n$ 的二进制数字需要 $O(\log n)$ 的表示长度。

目前提供三种自然数的编码方式：

- Church 自然数编码，其相关的内置函数都无后缀。构造函数采用一进制；运算函数的参数与结果均使用 Church 自然数编码；比较函数的参数使用 Church 自然数编码，结果使用布尔值编码
- Scott 自然数编码，其相关的内置函数都添加 `_S` 后缀。构造函数采用一进制；运算函数的参数与结果均使用 Scott 自然数编码；比较函数的参数使用 Scott 自然数编码，结果使用布尔值编码
- Binary 自然数编码，其相关的内置函数都添加 `_B` 后缀。构造函数采用二进制；运算函数的参数与结果均使用 Binary 自然数编码；比较函数的参数使用 Binary 自然数编码，结果使用布尔值编码

三种编码不可混用，且需要不同的解码方式，详见 [interpreter.md#解释器选项](interpreter.md#解释器选项)。

### 自然数构造

可以直接使用十进制阿拉伯数字表示 Church / Scott / Binary 自然数字面量。相关语法参见 [syntax.md#核心-λ-的字面量](syntax.md#核心-λ-的字面量)，编码选项参见 [compiler.md#编译器选项](compiler.md#编译器选项)。

#### Church 自然数编码

- `ZERO` 表示零
- `SUCC a` 表示自然数 `a` 的后继
- `ONE` / `TWO` / `THREE` / `FOUR` / `FIVE` / `SIX` / `SEVEN` / `EIGHT` / `NINE` / `TEN` 分别表示一到十

#### Scott 自然数编码

- `ZERO_S` 表示零
- `SUCC_S a` 表示自然数 `a` 的后继
- `ONE_S` / `TWO_S` / `THREE_S` / `FOUR_S` / `FIVE_S` / `SIX_S` / `SEVEN_S` / `EIGHT_S` / `NINE_S` / `TEN_S` 分别表示一到十

#### Binary 自然数编码

- `ZERO_B` 表示零
- `EVEN_B a` 表示 `a` 的两倍，`ODD_B a` 表示 `a` 的两倍加一
- `BIT_0` / `BIT_1` 分别是 `EVEN_B` / `ODD_B` 的别名
- `ONE_B` / `TWO_B` / `THREE_B` / `FOUR_B` / `FIVE_B` / `SIX_B` / `SEVEN_B` / `EIGHT_B` / `NINE_B` / `TEN_B` 分别表示一到十
- 前导零不影响数值，即 `BIT_0 ZERO_B` / `BIT_0 (BIT_0 ZERO_B)` 等仍表示零，`BIT_1 (BIT_0 ZERO_B)` / `BIT_1 (BIT_0 (BIT_0 ZERO_B))` 等仍表示一，以此类推

### 自然数运算

自然数运算的结果仍为自然数。

自然数一元运算：

- `PRED a` 表示自然数 `a` 的前驱。零的前驱仍为零
- `FACT a` 表示自然数 `a` 的阶乘

自然数二元对称运算：

- `ADD a b` 表示自然数 `a` 和自然数 `b` 的加法
- `MUL a b` 表示自然数 `a` 和自然数 `b` 的乘法
- `GCD a b` 表示自然数 `a` 和自然数 `b` 的最大公因数。使用欧几里得算法，`GCD ZERO ZERO` 的结果为零
- `LCM a b` 表示自然数 `a` 和自然数 `b` 的最小公倍数。任一参数为零时结果为零
- `MAX a b` 返回自然数 `a` 和自然数 `b` 中较大的值
- `MIN a b` 返回自然数 `a` 和自然数 `b` 中较小的值

自然数二元不对称运算：

- `SUB a b` 表示自然数 `a` 和自然数 `b` 的减法。减法的结果截断到零
- `POW a b` 表示自然数 `a` 和自然数 `b` 的幂
- `DIV a b` 表示自然数 `a` 除以自然数 `b` 的商。除数为零时结果为零
- `MOD a b` 表示自然数 `a` 除以自然数 `b` 的余数。除数为零时结果为 `a`
- `LOG a b` 表示以自然数 `a` 为底、自然数 `b` 为真数时的对数。结果向下取整。要求 `a` 大于一且 `b` 大于零

### 自然数比较

自然数比较在成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `ISZERO a` 判断自然数 `a` 是否为零
- `EQ a b` / `NEQ a b` 判断自然数 `a` 是否等于 / 不等于自然数 `b`
- `LT a b` / `LEQ a b` 判断自然数 `a` 是否小于 / 小于或等于自然数 `b`
- `GT a b` / `GEQ a b` 判断自然数 `a` 是否大于 / 大于或等于自然数 `b`

## 整数

整数的实现位于 [integer.lambda](../lib/integer.lambda)。

整数用自然数有序对表示，值为第一个自然数减去第二个自然数。

即整数表示为

```lambda
PAIR a b
```

其值为

$$
a - b
$$

其中 `a` 和 `b` 都是自然数。

### 整数构造

- `NTOZ n` 将自然数 `n` 构造为整数 `PAIR n ZERO`
- `NTOZ_NEG n` 将自然数 `n` 构造为整数 `PAIR ZERO n`
- `NTOZ_SUB a b` 将自然数 `a` 和自然数 `b` 的差作为整数

### 整数运算

整数运算的结果仍为整数。

整数的一元运算：

- `ZNEG a` 表示整数 `a` 取负
- `ZABS a` 表示整数 `a` 的绝对值
- `ZNORM a` 将整数 `a` 化简为一个分量为零的有序对。零化简为 `PAIR ZERO ZERO`

整数的二元对称运算：

- `ZADD a b` 表示整数 `a` 和整数 `b` 的加法
- `ZMUL a b` 表示整数 `a` 和整数 `b` 的乘法
- `ZMAX a b` 返回整数 `a` 和整数 `b` 中较大的值
- `ZMIN a b` 返回整数 `a` 和整数 `b` 中较小的值

整数的二元不对称运算：

- `ZSUB a b` 表示整数 `a` 和整数 `b` 的减法
- `ZDIV a b` 表述整数 `a` 除以整数 `b` 的商。结果向下取整。除数为零时结果为零
- `ZMOD a b` 返回整数 `a` 除以整数 `b` 的余数。除数非零时余数与除数同号或为零，除数为零时结果为 `a`
- `ZPOW a b` 表示整数 `a` 的自然数 `b` 次幂
- `ZLOG a b` 表示以整数 `a` 为底、整数 `b` 为真数时的对数。结果向下取整。要求 `a` 大于一且 `b` 大于零

### 整数比较

整数比较按数值进行，不要求输入已经经过 `ZNORM`。

整数比较在成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `ZISZERO a` 判断整数 `a` 是否为零整数
- `ZEQ a b` / `ZNEQ a b` 判断整数 `a` 是否等于 / 不等于整数 `b`
- `ZLT a b` / `ZLEQ a b` 判断整数 `a` 是否小于 / 小于或等于整数 `b`
- `ZGT a b` / `ZGEQ a b` 判断整数 `a` 是否大于 / 大于或等于整数 `b`

## 有理数

有理数的实现位于 [rational.lambda](../lib/rational.lambda)。

有理数用整数有序对表示，值为第一个整数除以第二个整数。

即有理数表示为

```lambda
PAIR a b
```

其值为

$$
\frac{a}{b}
$$

其中 `a` 是整数，`b` 是非零整数。

### 有理数构造

- `NTOQ n` 将自然数 `n` 构造为有理数
- `ZTOQ z` 将整数 `z` 构造为有理数
- `ZTOQ_DIV a b` 将整数 `a` 和非零整数 `b` 的商作为有理数
- `ZTOQ_POW a b` 将整数 `a` 的整数 `b` 次幂作为有理数。负指数要求 `a` 非零

### 有理数运算

有理数运算的结果仍为有理数。

有理数的一元运算：

- `QNEG a` 表示有理数 `a` 取负
- `QABS a` 表示有理数 `a` 的绝对值
- `QINV a` 表示非零有理数 `a` 的倒数。`a` 为零时结果不是有效有理数
- `QNORM a` 将有理数 `a` 化简为分母为正的最简分数。`a` 的分母必须是非零整数；`a` 的分子为零时化简结果为 `PAIR (NTOZ ZERO) (NTOZ ONE)`

有理数的二元对称运算：

- `QADD a b` 表示有理数 `a` 和有理数 `b` 的加法
- `QMUL a b` 表示有理数 `a` 和有理数 `b` 的乘法
- `QMAX a b` 返回有理数 `a` 和有理数 `b` 中较大的值。输入的分母必须非零
- `QMIN a b` 返回有理数 `a` 和有理数 `b` 中较小的值。输入的分母必须非零

有理数的二元不对称运算：

- `QSUB a b` 表示有理数 `a` 和有理数 `b` 的减法
- `QDIV a b` 表示有理数 `a` 和非零有理数 `b` 的除法
- `QPOW a b` 表示有理数 `a` 的整数 `b` 次幂。负指数要求 `a` 非零

### 有理数比较

有理数比较按数值进行，不要求输入已经经过 `QNORM`。输入的分母必须非零。

有理数比较成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `QISZERO a` 判断有理数 `a` 是否为零有理数
- `QEQ a b` / `QNEQ a b` 判断有理数 `a` 是否等于 / 不等于有理数 `b`
- `QLT a b` / `QLEQ a b` 判断有理数 `a` 是否小于 / 小于或等于有理数 `b`
- `QGT a b` / `QGEQ a b` 判断有理数 `a` 是否大于 / 大于或等于有理数 `b`

## 实数

实数的实现位于 [real.lambda](../lib/real.lambda)。

实数用柯西序列进行定义。

> 柯西序列是项最终彼此任意接近的有理数序列。
>
> 一个有理数序列表示为一个函数 $a$，其接受自然数并返回有理数
>
> $$
> a: \mathbb{N} \to \mathbb{Q}
> $$
>
> 若对每个自然数 $k$，都存在自然数 $N$ 使得对任意 $m,n \gt N$ 满足
>
> $$
> |a(m)-a(n)| \leq \frac{1}{k+1}
> $$
>
> 则称 $a$ 为柯西序列。

因此从有理数 `q` 构造实数时只需使用常值函数

```lambda
\q -> \n -> q
```

这表示无论自然数 `n` 是多少都返回 `q`，满足柯西序列的要求，从而是一个实数。

### 实数构造

- `NTOR n` 将自然数 `n` 构造为实数
- `ZTOR z` 将整数 `z` 构造为实数
- `QTOR q` 将有理数 `q` 构造为实数
- `QTOR_POW a b` 将有理数 `a` 的有理数 `b` 次幂作为实数。第 `n` 项为 $\operatorname{sgn}(a^p)\frac{\left\lfloor 2^n\sqrt[d]{|a^p|}\right\rfloor}{2^n}$
- `QTOR_LOG a b` 将以有理数 `a` 为底、有理数 `b` 为真数的对数作为实数。要求 `a` 大于零、`a` 不等于一且 `b` 大于零。第 `n` 项为 $\frac{\lfloor 2^n\log_a b\rfloor}{2^n}$
- `E` 表示自然常数 $e$。第 `n` 项为 $\sum_{k=0}^{n} \frac1{k!}$
- `PI` 表示圆周率 $\pi$。第 `n` 项为 $16\sum_{k=0}^{n}\frac{(-1)^k}{(2k+1)5^{2k+1}}-4\sum_{k=0}^{n}\frac{(-1)^k}{(2k+1)239^{2k+1}}$

### 实数运算

实数运算对柯西序列在相同索引处的有理数逐项进行计算。

实数运算的结果仍为实数。

实数的一元运算：

- `RNEG a` 表示实数 `a` 取负
- `RABS a` 表示实数 `a` 的绝对值
- `RINV a` 表示非零实数 `a` 的倒数
- `RNORM a n` 返回实数 `a` 在索引 `n` 处化简后的有理数
- `EXP r` 自然常数 $e$ 的实数 `r` 次幂
- `LN r` 以自然常数 $e$ 为底数、实数 `r` 为真数的对数
- `SIN r` 返回实数 `r` 的正弦。使用弧度制。第 `n` 项为 $\sum_{k=0}^{n}\frac{(-1)^k(r(n))^{2k+1}}{(2k+1)!}$
- `COS r` 返回实数 `r` 的余弦。使用弧度制。第 `n` 项为 $\sum_{k=0}^{n}\frac{(-1)^k(r(n))^{2k}}{(2k)!}$
- `ASIN r` 返回实数 `r` 的反正弦，主值范围为 $[-\pi/2,\pi/2]$。要求输入在 $[-1,1]$ 内。第 `n` 项为 $\sum_{k=0}^{n}\frac{(2k)!}{4^k(k!)^2(2k+1)}(r(n))^{2k+1}$
- `ACOS r` 返回实数 `r` 的反余弦，主值范围为 $[0,\pi]$。要求输入在 $[-1,1]$ 内。第 `n` 项为 $2\sum_{k=0}^{n}\frac{(-1)^k}{2k+1}-\sum_{k=0}^{n}\frac{(2k)!}{4^k(k!)^2(2k+1)}(r(n))^{2k+1}$

实数的二元对称运算：

- `RADD a b` 表示实数 `a` 和实数 `b` 的加法
- `RMUL a b` 表示实数 `a` 和实数 `b` 的乘法
- `RMAX a b` 返回实数 `a` 和 `b` 的逐项最大值
- `RMIN a b` 返回实数 `a` 和 `b` 的逐项最小值

实数的二元不对称运算：

- `RSUB a b` 表示实数 `a` 和实数 `b` 的减法
- `RDIV a b` 表示实数 `a` 除以非零实数 `b`
- `RPOW a b` 表示实数 `a` 的实数 `b` 次幂。第 `n` 项为 `QTOR_POW (a n) (b n) n`
- `RLOG a b` 返回以实数 `a` 为底、实数 `b` 为真数的对数。要求 `a` 大于零、`a` 不等于一且 `b` 大于零。第 `n` 项为 `QTOR_LOG (a n) (b n) n`

### 实数比较

实数比较柯西序列在自然数索引 `n` 处的有理数。

- `RISZERO a n` 判断 `a n` 是否为零
- `REQ a b n` / `RNEQ a b n` 判断 `a n` 是否等于 / 不等于 `b n`
- `RLT a b n` / `RLEQ a b n` 判断 `a n` 是否小于 / 小于或等于 `b n`
- `RGT a b n` / `RGEQ a b n` 判断 `a n` 是否大于 / 大于或等于 `b n`

## 字符串

字符串使用 Church 有序列表编码，列表中的每个元素是用 Binary 自然数编码的 Unicode 标量值。

字符的有效 Unicode 标量值范围是从 `0` 至 `0x10FFFF` 且排除从 `0xD800` 至 `0xDFFF` 的代理项。

### 字符串构造

可以直接使用双引号表示字符串字面量。相关语法参见 [syntax.md#核心-λ-的字面量](syntax.md#核心-λ-的字面量)，解码选项参见 [interpreter.md#解释器选项](interpreter.md#解释器选项)。

- `NIL` 表示空字符串
- `CONS a s` 表示将字符 `a` 放在字符串 `s` 开头的新字符串

### 字符串操作

字符串就是元素为 Binary 自然数的 Church 有序列表，可以使用所有 Church 有序列表的 [有序列表操作](#有序列表操作)。
