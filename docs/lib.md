# 标准库

核心 λ 标准库的所有内置函数都在项目的 `lib/` 目录中定义和导出。

## 组合子

### 基本组合子

- `I x` 返回 `x`，是恒等组合子
- `K x y` 返回 `x`，忽略第二个参数
- `S f g x` 返回 `f x (g x)`，将 `x` 同时传给 `f` 和 `g`

### 函数操作组合子

- `B f g x` 返回 `f (g x)`，将 `g` 的结果传给 `f`
- `C f x y` 返回 `f y x`，交换后两个参数
- `W f x` 返回 `f x x`，将参数 `x` 传入两次
- `M f` 返回 `f f`，将函数应用于自身
- `T x f` 返回 `f x`，先给出参数，再给出函数
- `V x y f` 返回 `f x y`，先给出两个参数，再给出函数
- `D f g h x` 返回 `f (g (h x))`，依次应用 `h`、`g` 和 `f`

### 不动点组合子

- `Y f` 满足 `Y f = f (Y f)`，适合非严格求值的递归
- `Z f` 满足 `Z f = f (Z f)`，适合严格求值的递归
- `A x f` 返回 `f (x x f)`，用于构造 `THETA`
- `THETA f` 满足 `THETA f = f (THETA f)`，适合非严格求值的递归，且展开速度通常比 `Y` 更快

## 高阶函数

- `ID x` 返回 `x`
- `COMPOSE f g x` 返回 `f (g x)`，表示函数复合
- `CONST x y` 返回 `x`，可用于构造常值函数
- `FLIP f x y` 返回 `f y x`，交换二元函数的参数顺序
- `CURRY f x y` 返回 `f (PAIR x y)`，将接收有序对的函数改为逐个接收参数
- `UNCURRY f p` 返回 `f (FST p) (SND p)`，将二元函数改为接收有序对

## 控制

### 条件

- `IF b t f` 当 `b` 为真值时选择 `t`，当 `b` 为假值时选择 `f`

### 递归

- `FIX f` 表示函数 `f` 的不动点，可用于定义递归函数。当前实现采用 `Y` 组合子

### 循环

- `FOR n s i` 从 `i` 作为初始状态，执行 `s` 共 `n` 次，输出最终状态
- `WHILE c s i` 从 `i` 作为初始状态，当 `c` 对当前状态返回真值时执行 `s`，当 `c` 对当前状态返回假值时输出最终状态

## 布尔值

### 布尔值构造

- `FALSE` 表示假值
- `TRUE` 表示真值

### 布尔值运算

- `AND a b` 表示布尔值 `a` 和布尔值 `b` 的与运算
- `OR a b` 表示布尔值 `a` 和布尔值 `b` 或运算
- `NOT a` 表示布尔值 `a` 的非运算

## 有序对

### 有序对构造

- `PAIR a b` 构造第一个分量为 `a`、第二个分量为 `b` 的有序对

### 有序对运算

- `FST p` 获取有序对 `p` 的第一个分量
- `SND p` 获取有序对 `p` 的第二个分量

## 自然数

自然数使用皮亚诺公理进行定义。

一是零的后继

```lambda
SUCC ZERO
```

二是一的后继

```lambda
SUCC (SUCC ZERO)
```

以此类推。

目前的算术系统中包含两种编码：

- Church 编码无后缀，为 `ZERO` / `SUCC`
- Scott 编码使用 `S` 后缀，为 `ZERO_S` / `SUCC_S`

两种编码不可混用，且需要不同的解码方式。

### 自然数构造

- `ZERO` 表示零
- `SUCC a` 表示自然数 `a` 的后继
- `ONE` / `TWO` / `THREE` / `FOUR` / `FIVE` / `SIX` / `SEVEN` / `EIGHT` / `NINE` 分别表示一到九

### 自然数运算

自然数运算的结果仍为自然数。

自然数一元运算：

- `PRED a` 表示自然数 `a` 的前驱。零的前驱仍为零
- `FACT a` 表示自然数 `a` 的阶乘

自然数二元对称运算：

- `ADD a b` 表示自然数 `a` 和自然数 `b` 的加法
- `MUL a b` 表示自然数 `a` 和自然数 `b` 的乘法
- `GCD a b` 表示自然数 `a` 和自然数 `b` 的最大公因数。使用欧几里得算法，`GCD ZERO ZERO` 的结果为零
- `LCM a b` 表示自然数 `a` 和自然数 `b` 的最小公倍数。任一参数为零时结果为零
- `MAX a b` 返回自然数 `a` 和自然数 `b` 中较大的值
- `MIN a b` 返回自然数 `a` 和自然数 `b` 中较小的值

自然数二元不对称运算：

- `SUB a b` 表示自然数 `a` 和自然数 `b` 的减法。减法的结果截断到零
- `POW a b` 表示自然数 `a` 和自然数 `b` 的幂
- `DIV a b` 表示自然数 `a` 除以自然数 `b` 的商。除数为零时结果为零
- `MOD a b` 表示自然数 `a` 除以自然数 `b` 的余数。除数为零时结果为 `a`
- `LOG a b` 表示以自然数 `a` 为底、自然数 `b` 为真数时的对数。结果向下取整。要求 `a` 大于一且 `b` 大于零

### 自然数比较

自然数比较在成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `ISZERO a` 判断自然数 `a` 是否为零
- `EQ a b` / `NEQ a b` 判断自然数 `a` 是否等于 / 不等于自然数 `b`
- `LT a b` / `LEQ a b` 判断自然数 `a` 是否小于 / 小于或等于自然数 `b`
- `GT a b` / `GEQ a b` 判断自然数 `a` 是否大于 / 大于或等于自然数 `b`

## 整数

整数用自然数有序对表示，值为第一个自然数减去第二个自然数。

即整数表示为

```lambda
PAIR a b
```

其值为

$$
a - b
$$

其中 `a` 和 `b` 都是自然数。

### 整数构造

- `NTOZ n` 将自然数 `n` 构造为整数 `PAIR n ZERO`
- `NTOZ_NEG n` 将自然数 `n` 构造为整数 `PAIR ZERO n`
- `NTOZ_SUB a b` 将自然数 `a` 和自然数 `b` 的差作为整数

### 整数运算

整数运算的结果仍为整数。

整数的一元运算：

- `ZNEG a` 表示整数 `a` 取负
- `ZABS a` 表示整数 `a` 的绝对值
- `ZNORM a` 将整数 `a` 化简为一个分量为零的有序对。零化简为 `PAIR ZERO ZERO`

整数的二元对称运算：

- `ZADD a b` 表示整数 `a` 和整数 `b` 的加法
- `ZMUL a b` 表示整数 `a` 和整数 `b` 的乘法
- `ZMAX a b` 返回整数 `a` 和整数 `b` 中较大的值
- `ZMIN a b` 返回整数 `a` 和整数 `b` 中较小的值

整数的二元不对称运算：

- `ZSUB a b` 表示整数 `a` 和整数 `b` 的减法
- `ZDIV a b` 表述整数 `a` 除以整数 `b` 的商。结果向下取整。除数为零时结果为零
- `ZMOD a b` 返回整数 `a` 除以整数 `b` 的余数。除数非零时余数与除数同号或为零，除数为零时结果为 `a`
- `ZPOW a b` 表示整数 `a` 的自然数 `b` 次幂
- `ZLOG a b` 表示以整数 `a` 为底、整数 `b` 为真数时的对数。结果向下取整。要求 `a` 大于一且 `b` 大于零

### 整数比较

整数比较按数值进行，不要求输入已经经过 `ZNORM`。

整数比较在成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `ZISZERO a` 判断整数 `a` 是否为零整数
- `ZEQ a b` / `ZNEQ a b` 判断整数 `a` 是否等于 / 不等于整数 `b`
- `ZLT a b` / `ZLEQ a b` 判断整数 `a` 是否小于 / 小于或等于整数 `b`
- `ZGT a b` / `ZGEQ a b` 判断整数 `a` 是否大于 / 大于或等于整数 `b`

## 有理数

有理数用整数有序对表示，值为第一个整数除以第二个整数。

即有理数表示为

```lambda
PAIR a b
```

其值为

$$
\frac{a}{b}
$$

其中 `a` 是整数，`b` 是非零整数。

### 有理数构造

- `NTOQ n` 将自然数 `n` 构造为有理数
- `ZTOQ z` 将整数 `z` 构造为有理数
- `ZTOQ_DIV a b` 将整数 `a` 和非零整数 `b` 的商作为有理数
- `ZTOQ_POW a b` 将整数 `a` 的整数 `b` 次幂作为有理数。负指数要求 `a` 非零

### 有理数运算

有理数运算的结果仍为有理数。

有理数的一元运算：

- `QNEG a` 表示有理数 `a` 取负
- `QABS a` 表示有理数 `a` 的绝对值
- `QINV a` 表示非零有理数 `a` 的倒数。`a` 为零时结果不是有效有理数
- `QNORM a` 将有理数 `a` 化简为分母为正的最简分数。`a` 的分母必须是非零整数；`a` 的分子为零时化简结果为 `PAIR (NTOZ ZERO) (NTOZ ONE)`

有理数的二元对称运算：

- `QADD a b` 表示有理数 `a` 和有理数 `b` 的加法
- `QMUL a b` 表示有理数 `a` 和有理数 `b` 的乘法
- `QMAX a b` 返回有理数 `a` 和有理数 `b` 中较大的值。输入的分母必须非零
- `QMIN a b` 返回有理数 `a` 和有理数 `b` 中较小的值。输入的分母必须非零

有理数的二元不对称运算：

- `QSUB a b` 表示有理数 `a` 和有理数 `b` 的减法
- `QDIV a b` 表示有理数 `a` 和非零有理数 `b` 的除法
- `QPOW a b` 表示有理数 `a` 的整数 `b` 次幂。负指数要求 `a` 非零

### 有理数比较

有理数比较按数值进行，不要求输入已经经过 `QNORM`。输入的分母必须非零。

有理数比较成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `QISZERO a` 判断有理数 `a` 是否为零有理数
- `QEQ a b` / `QNEQ a b` 判断有理数 `a` 是否等于 / 不等于有理数 `b`
- `QLT a b` / `QLEQ a b` 判断有理数 `a` 是否小于 / 小于或等于有理数 `b`
- `QGT a b` / `QGEQ a b` 判断有理数 `a` 是否大于 / 大于或等于有理数 `b`

## 实数

实数用柯西序列进行定义。

> 柯西序列是项最终彼此任意接近的有理数序列。
>
> 一个有理数序列表示为一个函数 $a$，其接受自然数并返回有理数
>
> $$
> a: \mathbb{N} \to \mathbb{Q}
> $$
>
> 若对每个自然数 $k$，都存在自然数 $N$ 使得对任意 $m,n \gt N$ 满足
>
> $$
> |a(m)-a(n)| \leq \frac{1}{k+1}
> $$
> 则称 $a$ 为柯西序列。

因此从有理数 `q` 构造实数时只需使用常值函数

```lambda
\q -> \n -> q
```

这表示无论自然数 `n` 是多少都返回 `q`，满足柯西序列的要求，从而是一个实数。

### 实数构造

- `NTOR n` 将自然数 `n` 构造为实数
- `ZTOR z` 将整数 `z` 构造为实数
- `QTOR q` 将有理数 `q` 构造为实数
- `QTOR_POW a b` 将有理数 `a` 的有理数 `b` 次幂作为实数。第 `n` 项为 $\operatorname{sgn}(a^p)\frac{\left\lfloor 2^n\sqrt[d]{|a^p|}\right\rfloor}{2^n}$
- `QTOR_LOG a b` 将以有理数 `a` 为底、有理数 `b` 为真数的对数作为实数。要求 `a` 大于零、`a` 不等于一且 `b` 大于零。第 `n` 项为 $\frac{\lfloor 2^n\log_a b\rfloor}{2^n}$
- `E` 表示自然常数 $e$。第 `n` 项为 $\sum_{k=0}^{n} \frac1{k!}$
- `PI` 表示圆周率 $\pi$。第 `n` 项为 $16\sum_{k=0}^{n}\frac{(-1)^k}{(2k+1)5^{2k+1}}-4\sum_{k=0}^{n}\frac{(-1)^k}{(2k+1)239^{2k+1}}$

### 实数运算

实数运算对柯西序列在相同索引处的有理数逐项进行计算。

实数运算的结果仍为实数。

实数的一元运算：

- `RNEG a` 表示实数 `a` 取负
- `RABS a` 表示实数 `a` 的绝对值
- `RINV a` 表示非零实数 `a` 的倒数
- `RNORM a n` 返回实数 `a` 在索引 `n` 处化简后的有理数
- `EXP r` 自然常数 $e$ 的实数 `r` 次幂
- `LN r` 以自然常数 $e$ 为底数、实数 `r` 为真数的对数

实数的二元对称运算：

- `RADD a b` 表示实数 `a` 和实数 `b` 的加法
- `RMUL a b` 表示实数 `a` 和实数 `b` 的乘法
- `RMAX a b` 返回实数 `a` 和 `b` 的逐项最大值
- `RMIN a b` 返回实数 `a` 和 `b` 的逐项最小值

实数的二元不对称运算：

- `RSUB a b` 表示实数 `a` 和实数 `b` 的减法
- `RDIV a b` 表示实数 `a` 除以非零实数 `b`
- `RPOW a b` 表示实数 `a` 的实数 `b` 次幂。第 `n` 项为 `QTOR_POW (a n) (b n) n`
- `RLOG a b` 返回以实数 `a` 为底、实数 `b` 为真数的对数。要求 `a` 大于零、`a` 不等于一且 `b` 大于零。第 `n` 项为 `QTOR_LOG (a n) (b n) n`

### 实数比较

实数比较柯西序列在自然数索引 `n` 处的有理数。

- `RISZERO a n` 判断 `a n` 是否为零
- `REQ a b n` / `RNEQ a b n` 判断 `a n` 是否等于 / 不等于 `b n`
- `RLT a b n` / `RLEQ a b n` 判断 `a n` 是否小于 / 小于或等于 `b n`
- `RGT a b n` / `RGEQ a b n` 判断 `a n` 是否大于 / 大于或等于 `b n`
