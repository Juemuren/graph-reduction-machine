## 纯 λ

一个纯 λ 程序就是一个由变量、单参数抽象、函数应用组成表达式。例如：

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个单参数抽象，可视为输入 `x`、输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `(\x -> x) (\y -> y)` 表示 `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 函数

因此整个表达式在规约后等价于：

```lambda
\y -> y
```

### 纯 λ 的语法约定

- 用 `\x -> 表达式` 定义单参数函数。多参数函数需要使用嵌套抽象，比如 `\x -> \y -> x`
- 用 `f x` 表示函数应用。函数应用为左结合，优先于抽象。括号可改变结合顺序，因此 `f x y` 等价于 `(f x) y`
- 变量名以小写字母开头，后面可以接字母、数字或下划线
- 使用 `#` 开始行注释
- 解析器允许自由变量，但编译器会拒绝自由变量。因为纯 SKI 图只有 `S`、`K`、`I` 和应用，只能表示闭合的 λ 表达式

## 核心 λ

核心 λ 由变量、单参数抽象、函数应用和内置函数组成。

### 核心 λ 的语法约定

核心 λ 遵循[纯 λ 的语法约定](#纯-λ-的语法约定)。

在此基础上：

- 所有内置函数都是一等函数，可部分应用
- 所有内置函数都遵循函数应用的结合顺序和优先级规则

### 丘奇编码

核心 λ 的内置函数可以通过丘奇编码展开为纯 λ。

丘奇编码的展开是递归的。如果展开式中仍然含有内置函数，则该内置函数会继续展开。

#### 布尔值

| 内置函数 | 展开式               |
| -------- | -------------------- |
| `FALSE`  | `\t -> \f -> f`      |
| `TRUE`   | `\t -> \f -> t`      |
| `AND`    | `\p -> \q -> p q p`  |
| `OR`     | `\p -> \q -> p p q`  |
| `NOT`    | `\p -> p FALSE TRUE` |

其中：

- `FALSE` 表示假植
- `TRUE` 表示真值
- `AND a b` 表示布尔值 `a` 和布尔值 `b` 的与运算
- `OR a b` 表示布尔值 `a` 和布尔值 `b` 或运算
- `NOT a` 表示布尔值 `a` 的非运算

#### 条件

| 内置函数 | 展开式                    |
| -------- | ------------------------- |
| `IF`     | `\b -> \t -> \f -> b t f` |

其中：

- `IF b t f` 当 `b` 为真值时选择 `t`，当 `b` 为假值时选择 `f`

#### 递归

| 内置函数 | 展开式                                  |
| -------- | --------------------------------------- |
| `Y`      | `\f -> (\x -> f (x x)) (\x -> f (x x))` |

其中：

- `Y f` 表示函数 `f` 的不动点，可用于定义递归函数

#### 循环

| 内置函数 | 展开式                                                     |
| -------- | ---------------------------------------------------------- |
| `FOR`    | `\n -> \s -> \i -> n s i`                                  |
| `WHILE`  | `\c -> \s -> \i -> Y (\l -> \x -> IF (c x) (l (s x)) x) i` |

其中：

- `FOR n s i` 从 `i` 开始执行 `s` 共 `n` 次，返回最终状态
- `WHILE c s i` 从 `i` 开始，在 `c` 对当前状态返回真值时执行 `s`，在返回假值时返回最终状态

无限循环在编译时没有完整范式。若要交由解释器执行，编译时使用 `--disable-reduce=both`。

#### 有序对

| 内置函数 | 展开式                    |
| -------- | ------------------------- |
| `PAIR`   | `\a -> \b -> \s -> s a b` |
| `FST`    | `\p -> p (\a -> \b -> a)` |
| `SND`    | `\p -> p (\a -> \b -> b)` |

其中：

- `PAIR a b` 表示第一个分量为 `a`、第二个分量为 `b` 的有序对
- `FST p` 表示有序对 `p` 的第一个分量
- `SND p` 表示有序对 `p` 的第二个分量

#### 自然数

| 内置函数 | 展开式                                                          |
| -------- | --------------------------------------------------------------- |
| `ZERO`   | `\f -> \x -> x`                                                 |
| `ONE`    | `\f -> \x -> f x`                                               |
| `SUCC`   | `\n -> \f -> \x -> f (n f x)`                                   |
| `PRED`   | `\n -> \f -> \x -> n (\g -> \h -> h (g f)) (\u -> x) (\u -> u)` |

自然数编码使用皮亚诺公理进行定义。

即一是零的后继

```lambda
SUCC ZERO
```

二是一的后继

```lambda
SUCC (SUCC ZERO)
```

以此类推。

因此：

- `ZERO` 表示零
- `ONE` 表示一
- `SUCC a` 表示自然数 `a` 的后继
- `PRED a` 表示自然数 `a` 的前驱。零的前驱仍为零

#### 自然数比较

| 内置函数 | 展开式                                |
| -------- | ------------------------------------- |
| `ISZERO` | `\n -> n (\x -> FALSE) TRUE`          |
| `LEQ`    | `\m -> \n -> ISZERO (SUB m n)`        |
| `LT`     | `\m -> \n -> NOT (LEQ n m)`           |
| `GEQ`    | `\m -> \n -> LEQ n m`                 |
| `GT`     | `\m -> \n -> NOT (LEQ m n)`           |
| `EQ`     | `\m -> \n -> AND (LEQ m n) (LEQ n m)` |
| `NEQ`    | `\m -> \n -> NOT (EQ m n)`            |

自然数比较函数在成立时得到真值，不成立时得到假值。

其中：

- `ISZERO a` 表示比较自然数 `a` 是否为零
- `LEQ a b` 表示比较自然数 `a` 是否小于或等于自然数 `b`
- `LT a b` 表示比较自然数 `a` 是否小于自然数 `b`
- `GEQ a b` 表示比较自然数 `a` 是否大于或等于自然数 `b`
- `GT a b` 表示比较自然数 `a` 是否大于自然数 `b`
- `EQ a b` 表示比较自然数 `a` 和自然数 `b` 是否相等
- `NEQ a b` 表示比较自然数 `a` 和自然数 `b` 是否不相等

#### 自然数运算

| 内置函数 | 展开式                                                                                                             |
| -------- | ------------------------------------------------------------------------------------------------------------------ |
| `ADD`    | `\m -> \n -> \f -> \x -> m f (n f x)`                                                                              |
| `SUB`    | `\m -> \n -> n PRED m`                                                                                             |
| `MUL`    | `\m -> \n -> \f -> m (n f)`                                                                                        |
| `POW`    | `\m -> \n -> n m`                                                                                                  |
| `FACT`   | `\n -> SND (FOR n (\p -> PAIR (SUCC (FST p)) (MUL (SUCC (FST p)) (SND p))) (PAIR ZERO ONE))`                       |
| `STEP`   | `\n -> \p -> IF (LEQ n (SUCC (SND p))) (PAIR (SUCC (FST p)) (SUB (SUCC (SND p)) n)) (PAIR (FST p) (SUCC (SND p)))` |
| `DIV`    | `\m -> \n -> FST (IF (ISZERO n) (PAIR ZERO m) (m (STEP n) (PAIR ZERO ZERO)))`                                      |
| `MOD`    | `\m -> \n -> SND (IF (ISZERO n) (PAIR ZERO m) (m (STEP n) (PAIR ZERO ZERO)))`                                      |
| `GCD`    | `\m -> \n -> FST (WHILE (\p -> NOT (ISZERO (SND p))) (\p -> PAIR (SND p) (MOD (FST p) (SND p))) (PAIR m n))`       |
| `LCM`    | `\m -> \n -> IF (OR (ISZERO m) (ISZERO n)) ZERO (DIV (MUL m n) (GCD m n))`                                         |

其中：

- `ADD a b` 表示自然数 `a` 和自然数 `b` 的加法
- `SUB a b` 表示自然数 `a` 和自然数 `b` 的减法。减法的结果截断到零
- `MUL a b` 表示自然数 `a` 和自然数 `b` 的乘法
- `POW a b` 表示自然数 `a` 和自然数 `b` 的幂运算
- `FACT a` 表示自然数 `a` 的阶乘，`FACT ZERO` 的结果为一
- `STEP n p` 表示对除数 `n` 和商、余数有序对 `p` 进行一次迭代，得到更新后的商、余数有序对
- `DIV a b` 表示自然数 `a` 除以自然数 `b` 的商。除数为零时，`DIV a ZERO` 的结果为零
- `MOD a b` 表示自然数 `a` 除以自然数 `b` 的余数。除数为零时，`MOD a ZERO` 的结果为 `a`
- `GCD a b` 表示自然数 `a` 和自然数 `b` 的最大公因数。使用欧几里得算法，`GCD ZERO ZERO` 的结果为零
- `LCM a b` 表示自然数 `a` 和自然数 `b` 的最小公倍数。任一参数为零时结果为零

#### 整数

| 内置函数 | 展开式              |
| -------- | ------------------- |
| `INT`    | `\n -> PAIR n ZERO` |

整数用自然数有序对表示，值为第一个自然数减去第二个自然数。

即整数表示为

```lambda
PAIR a b
```

其值为

$$
a - b
$$

其中 `a` 和 `b` 都是自然数。

因此：

- `INT n` 将自然数 `n` 构造为整数

#### 整数运算

| 内置函数 | 展开式                                                                                                                 |
| -------- | ---------------------------------------------------------------------------------------------------------------------- |
| `NEG`    | `\p -> PAIR (SND p) (FST p)`                                                                                           |
| `ABS`    | `\p -> PAIR (ADD (SUB (FST p) (SND p)) (SUB (SND p) (FST p))) ZERO`                                                    |
| `ZADD`   | `\p -> \q -> PAIR (ADD (FST p) (FST q)) (ADD (SND p) (SND q))`                                                         |
| `ZSUB`   | `\p -> \q -> PAIR (ADD (FST p) (SND q)) (ADD (SND p) (FST q))`                                                         |
| `ZMUL`   | `\p -> \q -> PAIR (ADD (MUL (FST p) (FST q)) (MUL (SND p) (SND q))) (ADD (MUL (FST p) (SND q)) (MUL (SND p) (FST q)))` |
| `ZNORM`  | `\p -> PAIR (SUB (FST p) (SND p)) (SUB (SND p) (FST p))`                                                               |

其中：

- `NEG a` 表示整数 `a` 取负
- `ABS a` 表示整数 `a` 的绝对值
- `ZADD a b` 表示整数 `a` 和整数 `b` 的加法
- `ZSUB a b` 表示整数 `a` 和整数 `b` 的减法
- `ZMUL a b` 表示整数 `a` 和整数 `b` 的乘法
- `ZNORM a` 将整数 `a` 化简为一个分量为零的有序对。零化简为 `PAIR ZERO ZERO`

#### 有理数

| 内置函数 | 展开式                   |
| -------- | ------------------------ |
| `RAT`    | `\z -> PAIR z (INT ONE)` |

有理数用整数有序对表示，值为第一个整数除以第二个整数。

即有理数表示为

```lambda
PAIR a b
```

其值为

$$
\frac{a}{b}
$$

其中 `a` 是整数，`b` 是非零整数。

因此：

- `RAT z` 将整数 `z` 构造为有理数

#### 有理数运算

| 内置函数 | 展开式                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------- |
| `QADD`   | `\p -> \q -> PAIR (ZADD (ZMUL (FST p) (SND q)) (ZMUL (FST q) (SND p))) (ZMUL (SND p) (SND q))` |
| `QSUB`   | `\p -> \q -> PAIR (ZSUB (ZMUL (FST p) (SND q)) (ZMUL (FST q) (SND p))) (ZMUL (SND p) (SND q))` |
| `QMUL`   | `\p -> \q -> PAIR (ZMUL (FST p) (FST q)) (ZMUL (SND p) (SND q))`                               |
| `QDIV`   | `\p -> \q -> PAIR (ZMUL (FST p) (SND q)) (ZMUL (SND p) (FST q))`                               |
| `QNORM`  | 见下文                                                                                         |

其中：

- `QADD a b` 表示有理数 `a` 和有理数 `b` 的加法
- `QSUB a b` 表示有理数 `a` 和有理数 `b` 的减法
- `QMUL a b` 表示有理数 `a` 和有理数 `b` 的乘法
- `QDIV a b` 表示有理数 `a` 和非零有理数 `b` 的除法
- `QNORM a` 将有理数 `a` 化简为分母为正的最简分数

`QNORM` 完整的展开为其丘奇编码展开式使用以下嵌套应用，其中 `a` 和 `b` 是已由 `ZNORM` 化简的分子与分母，`g` 是两者绝对值的最大公因数：

```lambda
\p ->
  (\a -> (\b -> (\g ->
    PAIR
      (
        PAIR
        (DIV (FST (IF (ISZERO (FST b)) (NEG a) a)) g)
        (DIV (SND (IF (ISZERO (FST b)) (NEG a) a)) g)
      )
      (INT (DIV (ADD (FST b) (SND b)) g)))
    (GCD (ADD (FST a) (SND a)) (ADD (FST b) (SND b))))
    (ZNORM (SND p)))
    (ZNORM (FST p)
  )
```

`QNORM` 的输入分母必须是非零整数。分子为零时，结果为 `PAIR (INT ZERO) (INT ONE)`。

### 表达式编译

编译器会把核心 λ 表达式编译为 SKI 图。

编译步骤为：

1. 将核心 λ 展开为纯 λ
2. 拒绝含自由变量的程序
3. 对纯 λ 表达式进行 β 规约和 η 规约，直到得到完整范式：
   - β 规约将 `(\x -> t) u` 替换为 `t[x := u]`，替换时避免变量捕获，并优先规约最外层应用
   - η 规约将 `\x -> f x` 替换为 `f`，前提是 `x` 不在 `f` 中自由出现
4. 逐层消去 λ 抽象，将 `\x -> t` 按照规则转换为 SKI 组合子：
   - 若 `t` 不含 `x`，转换为 `K t`
   - 若 `t` 就是 `x`，转换为 `I`
   - 若 `t` 是应用 `u v`，转换为 `S (\x -> u) (\x -> v)`，并继续消去其中的抽象
5. 将组合子及其应用写成以 `#0` 为根的 SKI 图

可以在指定阶段后停止编译：

- 使用 `--stop-after=expand` 参数时，在展开后停止
- 使用 `--stop-after=reduce` 参数时，在规约后停止

可以禁用指定的规约：

- 使用 `--disable-reduce=beta` 禁用 β 规约
- 使用 `--disable-reduce=eta` 禁用 η 规约
- 使用 `--disable-reduce=both` 禁用所有规约

禁用规约也适用于 `--stop-after=reduce`。

## SKI 图

一个 SKI 图可以是一个纯 λ 程序的等价表示。例如以下图与 `(\x -> x) (\y -> y)` 等价：

```ski
#0 = #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. 约定 `#0` 为图的根节点
2. `#1 #2` 表示应用，`#1` 为函数，`#2` 为参数
3. `#0 = #1 #2;` 表示把应用的结果定义为根节点，或者理解为根节点的两条边分别连接到 `#1` 和 `#2` 节点
4. `#1 = I;` 和 `#2 = I;` 定义两个恒等组合子

因此整个图等价于

```ski
I I
```

归约的结果是

```ski
I
```

和此前的 λ 程序一致。

### SKI 图的语法约定

- 每个图文件必须定义根节点 `#0`。每个定义以分号结束
- 节点可以是 `S`、`K`、`I`，或 `函数节点 参数节点` 形式的应用
- 节点编号由 `#` 和十进制数字组成，按文本比较，因此 `#0` 与 `#00` 不同
- 编号不能重复，且每条边引用的节点必须在文件中定义。节点允许前向引用
- 使用 `--` 开始行注释
- 解析器允许环和不可达节点，但解释器会拒绝可达的环，并忽略不可达节点

### 图规约

解释器会对 SKI 图进行规约。

规约步骤为：

1. 从根节点 `#0` 开始，按规则改写节点：
   - `I x` 改写为 `x`
   - `K x y` 改写为 `x`
   - `S x y z` 改写为 `(x z) (y z)`
2. 继续规约该节点，然后递归规约节点的边；若规约后产生新的可规约应用，则继续改写
3. 当根节点可达的图中没有可规约应用时，输出最终的 SKI 图

每次组合子改写计为一步。

规约存在步数限制。超过 `--max-steps` 指定的步数时会报错。

### 丘奇解码

默认情况下，解释器不会尝试解码，因此输出仍是 SKI 图。

解码需要显式启用：

- 使用 `--decode=natural` 参数时，解释器会尝试解码自然数：把结果应用到符号参数 `f` 和 `x`，若归约结果为 `x` / `f x` / `f (f x)` 这类 `f` 对 `x` 的重复作用，则作用次数就是解码得到的自然数。解码成功后输出对应的十进制自然数，解码失败时报错。

- 使用 `--decode=boolean` 参数时，解释器会尝试解码布尔值：把结果应用到两个不同的符号参数，返回的是第一个参数则解码得到 `TRUE`，返回的是第二个参数则解码得到 `FALSE`。解码成功后输出对应的布尔值，解码失败时报错。

- 使用 `--decode=integer` 参数时，解释器会尝试解码整数：把结果应用到符号参数 `f`，若归约结果为 `f a b`，则分别按自然数解码 `a` 和 `b`，并把 `a - b` 的结果作为解码得到的整数。解码成功后输出对应的十进制整数，解码失败时报错。

- 使用 `--decode=rational` 参数时，解释器会尝试解码有理数：把结果应用到符号参数 `f`，若归约结果为 `f a b`，则分别按整数解码 `a` 和 `b`，并把 `a / b` 的结果作为解码得到的有理数。解码成功后输出约分后的分数，解码失败或分母为零时报错。

解码选项不能同时使用。布尔值 `FALSE` 与自然数 `0` 的编码相同，解码结果取决于所选选项。

解码过程也受 `--max-steps` 限制。
