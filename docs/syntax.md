# 语法

项目涉及多种语法：

- 给编译器的源代码，为 **带算术语法的 λ 表达式**，由 [ArithmeticLambda.cf](../grammar/ArithmeticLambda.cf) 定义
- 丘奇编码后的中间表示，为 **纯 λ 表达式**，由 [PureLambda.cf](../grammar/PureLambda.cf) 定义
- 给图归约机的机器码，为 **SKI 图**，由 [Graph.cf](../grammar/Graph.cf) 定义

## λ 表达式

一个 λ 程序就是一个表达式。例如 `example.lambda` 可以是：

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个输入 `x`，输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 自身

因此整个表达式在规约后等价于：

```lambda
\y -> y
```

### λ 表达式的语法约定

- 用 `\x -> 表达式` 定义单参数函数。多参数函数需要用到柯里化，比如 `\x -> \y -> x`
- 用 `f x` 表示函数应用，应用为左结合。例如 `f x y` 等价于 `(f x) y`
- 变量名以小写字母开头，后面可以接字母、数字或下划线
- 语法本身允许自由变量，但编译器会拒绝自由变量。因为纯 SKI 图只有 `S`、`K`、`I` 和应用，只能表示闭合的 λ 表达式

### 丘奇编码

项目的 λ 程序支持直接使用：

- 布尔值
- 自然数和自然数加法、乘法、幂
- 有序对和投影函数
- 整数

关于运算：

- 所有运算都提供全大写的内置函数
- 所有多元内置函数都支持部分应用
- 部分多元运算和一元运算提供语法糖

所有编码在编译时被展开为纯 λ 表达式。

#### 自然数编码

语法：

- 自然数表示为 `0`、`1`、`2`，要求是非负十进制整数
- 加法的表示为 `ADD a b`，等价于语法糖 `a + b`，后者从左向右结合
- 乘法的表示为 `MUL a b`，等价于语法糖 `a * b`，后者从左向右结合
- 幂的表示为 `POW a b`，等价于语法糖 `a ^ b`，后者从右向左结合

运算优先级为：

1. 幂
2. 乘法
3. 加法

展开：

- `0` 展开为 `\f -> \x -> x`，`1` 展开为 `\f -> \x -> f x`，`2` 展开为 `\f -> \x -> f (f x)`，以此类推
- `ADD a b` 和 `a + b` 都展开为 `(\m -> \n -> \f -> \x -> m f (n f x)) a b`
- `MUL a b` 和 `a * b` 都展开为 `(\m -> \n -> \f -> m (n f)) a b`
- `POW a b` 和`a ^ b` 都展开为 `(\m -> \n -> n m) a b`

#### 有序对编码

语法：

- `PAIR a b` 构造有序对
- `FST p` 取得有序对 `p` 的第一个分量
- `SND p` 取得有序对 `p` 的第二个分量

展开：

- `PAIR` 展开为 `\a -> \b -> \s -> s a b`
- `FST` 展开为 `\p -> p (\a -> \b -> a)`
- `SND` 展开为 `\p -> p (\a -> \b -> b)`

#### 整数编码

整数用自然数有序对表示，值为第一个自然数减去第二个自然数。

语法：

- 正整数 `+n` 表示为 `INT +n`，其中 `n` 是非零自然数
- 负整数 `-n` 表示为 `INT -n`，其中 `n` 是非零自然数
- `0` 可以表示为 `INT +0`，也可以表示为 `INT -0`。必须显式写出符号
- 整数也可以表示为 `PAIR a b`，其值为 `a - b`
- 取负表示为 `NEG a`，等价于语法糖 `-a`
- 整数加法表示为 `ZADD a b`，等价于语法糖 `a +z b`
- 整数减法表示为 `ZSUB a b`，等价于语法糖 `a -z b`

`+z` 和 `-z` 与自然数加法 `+` 具有相同优先级，均从左向右结合。

运算优先级为

1. 取负
2. 加法和减法

展开：

- `INT +n` 展开为 `PAIR n 0`，`INT -n` 展开为 `PAIR 0 n`。其中 `n` 是自然数。`PAIR` 与自然数会继续展开为纯 λ 表达式
- `NEG` 和 `-a` 都展开为 `(\p -> PAIR (SND p) (FST p)) a`。其中有序对及投影函数会继续展开为纯 λ 表达式
- `ZADD a b` 和 `a +z b` 都展开为 `(\p -> \q -> PAIR (ADD (FST p) (FST q)) (ADD (SND p) (SND q))) a b`
- `ZSUB a b` 和 `a -z b` 都展开为 `(\p -> \q -> PAIR (ADD (FST p) (SND q)) (ADD (SND p) (FST q))) a b`

整数加减法的结果仍是自然数有序对，不会消去两个分量中相同的部分。以上表达式中的内置函数会继续展开为纯 λ 表达式。

### 优先级顺序

解析优先级从高到低为：

1. 函数应用
2. 运算
3. 函数定义

运算内部仍然存在优先级，请参考对应类型的编码。

所有内置函数都是函数，遵循函数的结合规则。

### 表达式编译

编译器会把纯 λ 表达式编译为 SKI 图。

编译步骤为：

1. 把算术语法糖展开为纯 λ 表达式
2. 拒绝含自由变量的程序
3. 逐层消去 λ 抽象，将 `\x -> t` 按照规则转换为 SKI 组合子：
   - 若 `t` 不含 `x`，转换为 `K t`
   - 若 `t` 就是 `x`，转换为 `I`
   - 若 `t` 是应用 `u v`，转换为 `S (\x -> u) (\x -> v)`，并继续消去其中的抽象
4. 将组合子及其应用写成以 `#0` 为根的 SKI 图

## SKI 图

一个 SKI 图可以是一个 λ 程序的等价表示。例如 `example.ski` 与上述 `example.lambda` 等价：

```ski
#0 = #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. 约定 `#0` 为图的根节点
2. `#1 #2` 表示应用，`#1` 为函数，`#2` 为参数
3. `#0 = #1 #2;` 表示把应用的结果定义为根节点，或者理解为根节点的两条边分别连接到 `#1` 和 `#2` 节点
4. `#1 = I;` 和 `#2 = I;` 定义两个恒等组合子

因此整个图等价于

```ski
I I
```

归约的结果是

```ski
I
```

和此前的 λ 程序一致。

### SKI 图的语法约定

- 每个图文件必须定义根节点 `#0`。每个定义以分号结束
- 节点可以是 `S`、`K`、`I`，或 `函数节点 参数节点` 形式的应用
- 节点编号由 `#` 和十进制数字组成，按文本比较，因此 `#0` 与 `#00` 不同
- 编号不能重复，且每条边引用的节点必须在文件中定义。节点允许前向引用
- 语法本身允许环和不可达节点，但解释器会拒绝可达的环，并忽略不可达节点

### 图规约

解释器会对 SKI 图进行规约。

规约步骤为：

1. 从根节点 `#0` 开始，按规则改写节点：
   - `I x` 改写为 `x`
   - `K x y` 改写为 `x`
   - `S x y z` 改写为 `(x z) (y z)`
2. 继续规约该节点，然后递归规约节点的边；若规约后产生新的可规约应用，则继续改写
3. 当根节点可达的图中没有可规约应用时，输出最终的 SKI 图

每次组合子改写计为一步；超过 `--max-steps` 指定的步数时会报错。

### 丘奇解码

默认情况下，解释器不会尝试解码，因此输出仍是 SKI 图。

解码需要显式启用：

- 使用 `--decode-natural` 参数时，解释器会尝试解码自然数：把结果应用到符号参数 `f` 和 `x`，若归约结果为 `f` 对 `x` 的重复作用，则作用次数就是解码得到的自然数。解码成功后解释器会输出对应的十进制自然数，解码失败时报错。

- 使用 `--decode-boolean` 参数时，解释器会尝试解码布尔值：把结果应用到两个不同的符号参数，返回的是第一个参数则解码得到 `TRUE`，返回的是第二个参数则解码得到 `FALSE`。解码成功后解释器会输出对应的布尔值，解码失败时报错。

解码选项不能同时使用。布尔值 `FALSE` 与自然数 `0` 的编码相同，解码结果取决于所选选项。

解码过程受 `--max-steps` 限制。
