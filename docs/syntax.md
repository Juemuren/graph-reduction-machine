# 输入语法

有两种输入：给编译器的 **λ 表达式**，以及给图归约机的 **SKI 图**。

[Syntax.cf](../grammar/Syntax.cf) 是 λ 表达式与 SKI 图的唯一语法定义，使用 BNFC 的 LBNF 格式；构建时由此生成 Haskell 的抽象语法树、词法分析器、解析器和打印器。

## λ 表达式

一个 λ 程序就是一个表达式。例如 `example.lambda` 可以是：

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个输入 `x`，输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 自身

因此整个表达式在规约后等价于：

```lambda
\y -> y
```

写法约定：

- 用 `\x -> 表达式` 定义单参数函数。多参数函数需要用到柯里化，比如 `\x -> \y -> x`
- 用 `f x` 表示函数应用。应用为左结合，所以 `f x y` 等价于 `(f x) y`
- 变量名以小写字母开头，后面可以接字母、数字或下划线。`root` 和 `app` 是保留字，不可用作变量
- 语法允许自由变量，但编译成 SKI 图的 λ 表达式不能包含自由变量。因为纯 SKI 图只有 `S`、`K`、`I` 和应用节点，只能表示闭合的 λ 表达式。

## SKI 图

一个 SKI 图是一个 λ 程序对应的等价表达。例如 `example.ski` 是上述 `example.lambda` 的编译结果：

```ski
root #0;
#0 = app #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. `root #0;` 指定从 `#0` 节点开始运行
2. `#0 = app #1 #2;` 把 `#1` 当函数，`#2` 当参数
3. `#1 = I;` 和 `#2 = I;` 定义两个恒等组合子

因此整个图等价于

```ski
I I
```

归约的结果是

```ski
I
```

和此前的 λ 程序一致。

两条边引用同一个编号，就表示它们共享同一个节点。下面是另一份完整图文件，也表示 `I I`，但两个位置都引用 `#1`：

```text
root #0;
#0 = app #1 #1;
#1 = I;
```

写法约定：

- 每个图文件都以 `root` 开始，后面至少有一个节点定义。每个定义以分号结束
- 节点可以是 `S`、`K`、`I`，或 `app 函数节点 参数节点`
- 节点编号由 `#` 和十进制数字组成，按文本比较，因此 `#0` 与 `#00` 不同
- 编号不能重复，根节点和每条边引用的节点必须已定义
- 语法本身允许环和不可达节点，是否接受由后续解释器的实现决定

## 构建解析器

运行

```sh
cabal build
```

Cabal 会调用 BNFC、Alex 和 Happy，从 `grammar/Syntax.cf` 生成并编译 Haskell 解析器。

生成的文件保存在 `src/Syntax` 下，不需要进行手工修改，也不提交仓库。
