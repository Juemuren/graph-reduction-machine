## 纯 λ

一个纯 λ 程序就是一个由变量、单参数抽象、函数应用组成表达式。

### 纯 λ 的示例

对于纯 λ

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个单参数抽象，可视为输入 `x`、输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `(\x -> x) (\y -> y)` 表示 `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 函数

整个表达式在规约后等价于

```lambda
\y -> y
```

### 纯 λ 的语法约定

- 用 `\x -> 表达式` 定义单参数函数。多参数函数需要使用嵌套抽象，比如 `\x -> \y -> x`
- 用 `f x` 表示函数应用。函数应用为左结合，优先于抽象。括号可改变结合顺序，因此 `f x y` 等价于 `(f x) y`
- 变量名以小写字母开头，后面可以接字母、数字或下划线
- 使用 `#` 开始行注释
- 解析器允许自由变量，但编译器会拒绝自由变量。因为纯 SKI 图只有 `S`、`K`、`I` 和应用，只能表示闭合的 λ 表达式

## 核心 λ

核心 λ 在纯 λ 的基础上扩展语法，提供定义、导入、导出、程序入口和标准库。

### 核心 λ 的语法约定

核心 λ 遵循[纯 λ 的语法约定](#纯-λ-的语法约定)，并有额外的语法约定。

关于定义：

- 使用 `name = 表达式;` 进行定义，每个定义最后都需要分号表示结束
- 定义的名称要求小写字母开头，后续可包含字母、数字或下划线；建议采用小驼峰命名法
- 同一文件中前面的定义可以引用后面的定义，但循环引用会报错
- 函数参数可以遮蔽同名的定义，即函数参数与定义重名时，函数体内的名称表示函数参数

关于导入和导出：

- 使用 `@> name = 表达式;` 定义并导出名称
- 使用 `@< "./relative.lambda" (name1, name2);` 根据相对路径从另一个文件中导入定义
- 同一文件可以导出多个定义
- 导入定义与本地定义重名时会报错

关于程序入口：

- 使用 `@! 表达式;` 作为程序入口
- 入口必须写在文件最后，一个程序只能有一个入口
- 只有包含入口的程序才可以被编译为 SKI 图

关于标准库：

- 标准库不需要显式导入，标准库的所有内置函数在所有程序中都可用
- 内置函数为大写字母开头，遵循大写蛇形命名法
- 内置函数是一等函数，可部分应用
- 内置函数遵循函数应用的结合顺序和优先级规则

标准库的详细说明见 [syntax.md#丘奇编码](syntax.md#丘奇编码)。

### 丘奇编码

核心 λ 标准库的内置函数可以通过丘奇编码展开为纯 λ。

核心 λ 的所有内置函数都在项目的 `lib/` 目录中定义和导出。内置函数可引用其它内置函数，展开时会递归替换。

#### 高阶函数

- `ID x` 返回 `x`
- `COMPOSE f g x` 返回 `f (g x)`，表示函数复合
- `CONST x y` 返回 `x`，可用于构造常值函数
- `FLIP f x y` 返回 `f y x`，交换二元函数的参数顺序
- `CURRY f x y` 返回 `f (PAIR x y)`，将接收有序对的函数改为逐个接收参数
- `UNCURRY f p` 返回 `f (FST p) (SND p)`，将二元函数改为接收有序对
- `LIFT2 f a b n` 返回 `f (a n) (b n)`，让二元函数作用于两个函数在同一输入上的结果

#### 布尔值

##### 布尔值构造

- `FALSE` 表示假值
- `TRUE` 表示真值

##### 布尔值运算

- `AND a b` 表示布尔值 `a` 和布尔值 `b` 的与运算
- `OR a b` 表示布尔值 `a` 和布尔值 `b` 或运算
- `NOT a` 表示布尔值 `a` 的非运算

#### 有序对

##### 有序对构造

- `PAIR a b` 构造第一个分量为 `a`、第二个分量为 `b` 的有序对

##### 有序对运算

- `FST p` 获取有序对 `p` 的第一个分量
- `SND p` 获取有序对 `p` 的第二个分量

#### 自然数

自然数使用皮亚诺公理进行定义。

一是零的后继

```lambda
SUCC ZERO
```

二是一的后继

```lambda
SUCC (SUCC ZERO)
```

以此类推。

##### 自然数构造

- `ZERO` 表示零
- `ONE` / `TWO` / `THREE` / `FOUR` / `FIVE` / `SIX` / `SEVEN` / `EIGHT` / `NINE` 分别表示一到九
- `SUCC a` 表示自然数 `a` 的后继
- `PRED a` 表示自然数 `a` 的前驱。零的前驱仍为零

##### 自然数运算

- `ADD a b` 表示自然数 `a` 和自然数 `b` 的加法
- `SUB a b` 表示自然数 `a` 和自然数 `b` 的减法。减法的结果截断到零
- `MUL a b` 表示自然数 `a` 和自然数 `b` 的乘法
- `POW a b` 表示自然数 `a` 和自然数 `b` 的幂运算
- `FACT a` 表示自然数 `a` 的阶乘，`FACT ZERO` 的结果为一
- `DIV a b` 表示自然数 `a` 除以自然数 `b` 的商。除数为零时，`DIV a ZERO` 的结果为零
- `MOD a b` 表示自然数 `a` 除以自然数 `b` 的余数。除数为零时，`MOD a ZERO` 的结果为 `a`
- `GCD a b` 表示自然数 `a` 和自然数 `b` 的最大公因数。使用欧几里得算法，`GCD ZERO ZERO` 的结果为零
- `LCM a b` 表示自然数 `a` 和自然数 `b` 的最小公倍数。任一参数为零时结果为零

##### 自然数比较

自然数比较在成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `ISZERO a` 判断自然数 `a` 是否为零
- `EQ a b` / `NEQ a b` 判断自然数 `a` 是否等于 / 不等于自然数 `b`
- `LT a b` / `LEQ a b` 判断自然数 `a` 是否小于 / 小于或等于自然数 `b`
- `GT a b` / `GEQ a b` 判断自然数 `a` 是否大于 / 大于或等于自然数 `b`

#### 整数

整数用自然数有序对表示，值为第一个自然数减去第二个自然数。

即整数表示为

```lambda
PAIR a b
```

其值为

$$
a - b
$$

其中 `a` 和 `b` 都是自然数。

##### 整数构造

- `NTOZ n` 将自然数 `n` 构造为整数 `PAIR n ZERO`

##### 整数运算

- `ZADD a b` 表示整数 `a` 和整数 `b` 的加法
- `ZSUB a b` 表示整数 `a` 和整数 `b` 的减法
- `ZMUL a b` 表示整数 `a` 和整数 `b` 的乘法
- `ZNEG a` 表示整数 `a` 取负
- `ZABS a` 表示整数 `a` 的绝对值
- `ZNORM a` 将整数 `a` 化简为一个分量为零的有序对。零化简为 `PAIR ZERO ZERO`

##### 整数比较

整数比较按数值进行，不要求输入已经经过 `ZNORM`。

整数比较在成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `ZISZERO a` 判断整数 `a` 是否为零整数
- `ZEQ a b` / `ZNEQ a b` 判断整数 `a` 是否等于 / 不等于整数 `b`
- `ZLT a b` / `ZLEQ a b` 判断整数 `a` 是否小于 / 小于或等于整数 `b`
- `ZGT a b` / `ZGEQ a b` 判断整数 `a` 是否大于 / 大于或等于整数 `b`

#### 有理数

有理数用整数有序对表示，值为第一个整数除以第二个整数。

即有理数表示为

```lambda
PAIR a b
```

其值为

$$
\frac{a}{b}
$$

其中 `a` 是整数，`b` 是非零整数。

##### 有理数构造

- `NTOQ n` 将自然数 `n` 构造为有理数
- `ZTOQ z` 将整数 `z` 构造为有理数

##### 有理数运算

- `QADD a b` 表示有理数 `a` 和有理数 `b` 的加法
- `QSUB a b` 表示有理数 `a` 和有理数 `b` 的减法
- `QMUL a b` 表示有理数 `a` 和有理数 `b` 的乘法
- `QDIV a b` 表示有理数 `a` 和非零有理数 `b` 的除法
- `QNEG a` 表示有理数 `a` 取负
- `QABS a` 表示有理数 `a` 的绝对值
- `QINV a` 表示非零有理数 `a` 的倒数。`a` 为零时结果不是有效有理数
- `QNORM a` 将有理数 `a` 化简为分母为正的最简分数。`a` 的分母必须是非零整数，分子为零时结果为 `PAIR (NTOZ ZERO) (NTOZ ONE)`

##### 有理数比较

有理数比较按数值进行，不要求输入已经经过 `QNORM`。输入的分母必须非零。

有理数比较成立时返回 `TRUE`，不成立时返回 `FALSE`。

- `QISZERO a` 判断有理数 `a` 是否为零有理数
- `QEQ a b` / `QNEQ a b` 判断有理数 `a` 是否等于 / 不等于有理数 `b`
- `QLT a b` / `QLEQ a b` 判断有理数 `a` 是否小于 / 小于或等于有理数 `b`
- `QGT a b` / `QGEQ a b` 判断有理数 `a` 是否大于 / 大于或等于有理数 `b`

#### 实数

实数用柯西序列进行定义。

> 柯西序列是项最终彼此任意接近的有理数序列。
>
> 一个有理数序列表示为一个函数 $a$，其接受自然数并返回有理数
>
> $$
> a: \mathbb{N} \to \mathbb{Q}
> $$
>
> 若对每个自然数 $k$，都存在自然数 $N$ 使得对任意 $m,n \gt N$ 满足
>
> $$
> |a(m)-a(n)| \leq \frac{1}{k+1}
> $$
> 则称 $a$ 为柯西序列。

因此从有理数 `q` 构造实数时只需使用常值函数

```lambda
\q -> \n -> q
```

这表示无论自然数 `n` 是多少都返回 `q`，满足柯西序列的要求，从而是一个实数。

##### 实数构造

- `QTOR q` 将有理数 `q` 构造为实数
- `ZTOR z` 将整数 `z` 构造为实数
- `NTOR n` 将自然数 `n` 构造为实数

##### 递归

### 表达式编译

编译器会把核心 λ 程序编译为 SKI 图。

编译步骤为：

1. 把核心 λ 程序入口中指定的表达式展开为纯 λ
2. 拒绝含自由变量的表达式
3. 对纯 λ 表达式进行 β 规约和 η 规约，直到得到完整范式：
   - β 规约将 `(\x -> t) u` 替换为 `t[x := u]`，替换时避免变量捕获，并优先规约最外层应用
   - η 规约将 `\x -> f x` 替换为 `f`，前提是 `x` 不在 `f` 中自由出现
4. 逐层消去 λ 抽象，将 `\x -> t` 按照规则转换为 SKI 组合子：
   - 若 `t` 不含 `x`，转换为 `K t`
   - 若 `t` 就是 `x`，转换为 `I`
   - 若 `t` 是应用 `u v`，转换为 `S (\x -> u) (\x -> v)`，并继续消去其中的抽象
5. 将组合子及其应用写成以 `#0` 为根的 SKI 图

可以在指定阶段后停止编译：

- 使用 `--stop-after=expand` 参数时，在展开后停止
- 使用 `--stop-after=reduce` 参数时，在规约后停止

可以禁用指定的规约：

- 使用 `--disable-reduce=beta` 禁用 β 规约
- 使用 `--disable-reduce=eta` 禁用 η 规约
- 使用 `--disable-reduce=both` 禁用所有规约

禁用规约也适用于 `--stop-after=reduce`。

## SKI 图

一个 SKI 图可以是一个纯 λ 程序的等价表示。

### SKI 图的示例

对于 SKI 图

```ski
#0 = #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. 约定 `#0` 为图的根节点
2. `#1 #2` 表示应用，`#1` 为函数，`#2` 为参数
3. `#0 = #1 #2;` 表示把应用的结果定义为根节点，或者理解为根节点的两条边分别连接到 `#1` 和 `#2` 节点
4. `#1 = I;` 和 `#2 = I;` 定义两个恒等组合子

整个图等价于

```ski
I I
```

归约的结果是

```ski
I
```

和 λ 表达式 `(\x -> x) (\y -> y)` 的规约结果相同。

### SKI 图的语法约定

- 每个图文件必须定义根节点 `#0`。每个定义以分号结束
- 节点可以是 `S`、`K`、`I`，或 `函数节点 参数节点` 形式的应用
- 节点编号由 `#` 和十进制数字组成，按文本比较，因此 `#0` 与 `#00` 不同
- 编号不能重复，且每条边引用的节点必须在文件中定义。节点允许前向引用
- 使用 `--` 开始行注释
- 解析器允许环和不可达节点，但解释器会拒绝可达的环，并忽略不可达节点

### 图规约

解释器会对 SKI 图进行规约。

规约步骤为：

1. 从根节点 `#0` 开始，按规则改写节点：
   - `I x` 改写为 `x`
   - `K x y` 改写为 `x`
   - `S x y z` 改写为 `(x z) (y z)`
2. 继续规约该节点，然后递归规约节点的边；若规约后产生新的可规约应用，则继续改写
3. 当根节点可达的图中没有可规约应用时，输出最终的 SKI 图

每次组合子改写计为一步。

规约存在步数限制。超过 `--max-steps` 指定的步数时会报错。

### 丘奇解码

默认情况下，解释器不会尝试解码，因此输出仍是 SKI 图。

解码需要指定解码方式。解码方式不能同时使用，因为相同编码在不同解码方式下的结果可能不同。比如布尔值 `FALSE` 与自然数 `0` 的编码相同，但自然数解码得到 `0`，布尔值解码得到 `FALSE`。

解码过程也受 `--max-steps` 限制。

#### 布尔值解码

使用 `--decode=boolean` 参数时，解释器会尝试解码布尔值：把结果应用到两个不同的符号参数，返回的是第一个参数则解码得到 `TRUE`，返回的是第二个参数则解码得到 `FALSE`。

解码成功后输出对应的布尔值，解码失败时报错。

#### 自然数解码

使用 `--decode=natural` 参数时，解释器会尝试解码自然数：把结果应用到符号参数 `f` 和 `x`，若归约结果为 `x` / `f x` / `f (f x)` 这类 `f` 对 `x` 的重复作用，则作用次数就是解码得到的自然数。

解码成功后输出对应的十进制自然数，解码失败时报错。

#### 整数解码

使用 `--decode=integer` 参数时，解释器会尝试解码整数：把结果应用到符号参数 `f`，若归约结果为 `f a b`，则分别按自然数解码 `a` 和 `b`，并把 `a - b` 的结果作为解码得到的整数。

解码成功后输出对应的十进制整数，解码失败时报错。

#### 有理数解码

使用 `--decode=rational` 参数时，解释器会尝试解码有理数：把结果应用到符号参数 `f`，若归约结果为 `f a b`，则分别按整数解码 `a` 和 `b`，并把 `a / b` 的结果作为解码得到的有理数。

解码成功后输出约分后的分数，解码失败时报错。

#### 实数解码

使用 `--decode=real` 参数时，解释器会尝试解码实数：把结果视为有理数序列 `a`，计算指定自然数下标 `n` 处的有理数 `a n`，并把得到的结果作为解码得到的实数。

解码成功后输出约分后的分数，解码失败时报错。

默认下标为 `0`，使用 `--precision-real=N` 指定下标。其中 `N` 必须是非负整数。
