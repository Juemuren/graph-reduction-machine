## 纯 λ

纯 λ 程序是由函数抽象和函数应用组成的单个表达式。

### 纯 λ 的示例

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个单参数函数抽象，可视为输入 `x`、输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `(\x -> x) (\y -> y)` 表示 `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 函数

整个表达式在归约后等价于

```lambda
\y -> y
```

### 纯 λ 的语法约定

- 用 `\x -> 表达式` 表示单参数的函数抽象。多参数需要使用嵌套，比如 `\x -> \y -> x`
- 用 `f x` 表示单参数的函数应用。多参数需要使用嵌套，比如 `f x y`
- 函数应用为左结合，且优先于函数抽象。括号可改变结合顺序，因此 `f x y` 等价于 `(f x) y`，`\f -> \x -> f x` 等价于 `\f -> \x -> (f x)`
- 函数的变量名以小写字母开头，后面可以接字母、数字或下划线
- 使用 `#` 开始行注释
- 解析器允许自由变量，但编译器会拒绝自由变量。因为纯 SKI 图只有 S/K/I 节点 和应用节点，只能表示闭合的 λ 表达式

## 核心 λ

核心 λ 在纯 λ 的基础上扩展语法，提供定义、导入、导出、程序入口、标准库和字面量。

核心 λ 遵循[纯 λ 的语法约定](#纯-λ-的语法约定)，并有额外的语法约定。

### 核心 λ 的定义

- 使用 `name = 表达式;` 表示定义，每个定义最后都需要分号表示结束
- 定义的名称要求小写字母开头，后续可包含字母、数字或下划线；建议采用小驼峰命名法
- 同一文件中前面的定义可以引用后面的定义，但循环引用会报错
- 函数参数可以遮蔽同名的定义，即函数参数与定义重名时，函数体内的名称表示函数参数

### 核心 λ 的导入和导出

- 使用 `@> name = 表达式;` 表示定义并导出定义
- 使用 `@< "./relative.lambda" (name1, name2);` 根据相对路径从另一个文件中导入定义
- 同一文件可以导出多个定义
- 导入定义与本地定义重名时会报错

### 核心 λ 的程序入口

- 使用 `@! 表达式;` 作为程序入口，这种入口可以写在文件中的任意位置
- 也可以使用 `@! 表达式` / `表达式;` / `表达式` 作为程序入口，这种入口只能写在文件的末尾
- 一个程序只能有一个入口
- 只有包含入口的程序才可以被编译为 SKI 图

### 核心 λ 的标准库

- 标准库不需要显式导入，标准库的所有内置函数在所有程序中都可以直接使用
- 内置函数为大写字母开头，遵循大写蛇形命名法
- 内置函数是一等函数，可部分应用，且遵循函数应用的结合顺序与优先级规则

标准库的详细说明见 [lib.md](lib.md)。

### 核心 λ 的字面量

对于自然数字面量：

- 可以用十进制阿拉伯数字表示自然数，比如 `0`、`12`
- 自然数可以出现在定义和表达式中，可作为函数或参数使用

对于字符串字面量：

- 可以用双引号表示字符串，比如 `"Hello"`、`"中文"`、`""`
- 字符串支持 `\"`、`\\`、`\n`、`\t`、`\r` 和 `\f` 转义
- 字符串支持所有 Unicode 字符

字面量存在多种编码方式：

- 自然数各编码的表示方式见 [lib.md#自然数](lib.md#自然数)
- 字符串各编码的表示方式见 [lib.md#字符串](lib.md#字符串)
- 字面量的编码选项见 [compiler.md#编译器选项](compiler.md#编译器选项)

## SKI 图

SKI 图由 S/K/I 节点和应用节点组成，是闭合纯 λ 程序的等价表示。

### SKI 图的示例

```ski
#0 = #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. 约定 `#0` 为图的根节点
2. `#1 #2` 表示应用，其中 `#1` 为函数节点，`#2` 为参数节点
3. `#0 = #1 #2;` 表示把 `#0` 节点的两条边分别连接到 `#1` 节点和 `#2` 节点，归约时 `#0` 会被替换为 `#1` 应用到 `#2` 的结果
4. `#1 = I;` 和 `#2 = I;` 表示 `#1` 和 `#2` 节点是 `I` 节点

整个图在归约后等价于

```ski
#0 = I;
```

和 λ 表达式 `(\x -> x) (\y -> y)` 的归约结果相同。

### SKI 图的语法约定

- 每个图必须定义根节点 `#0`
- 用 `S`、`K`、`I` 分别表示 `S` 节点、`K` 节点、`I` 节点
- 用 `函数节点 参数节点` 表示应用节点
- 应用节点引用的节点必须在图中定义，允许前向引用
- 节点定义以分号结束
- 节点编号由 `#` 和十进制数字组成
- 节点编号不能重复。节点编号按文本比较，因此 `#0` 与 `#00` 是不同的节点
- 使用 `--` 开始行注释
- 解析器允许环和不可达节点，但解释器会拒绝可达的环，并忽略不可达的节点
