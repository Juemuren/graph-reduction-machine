# 语法

项目涉及多种语法：

- 给编译器的源代码，为 **带算术语法糖的 λ 表达式**，由 [ArithmeticLambda.cf](../grammar/ArithmeticLambda.cf) 定义
- 丘奇编码后的中间表示，为 **纯 λ 表达式**，由 [PureLambda.cf](../grammar/PureLambda.cf) 定义
- 给图归约机的机器码，为 **SKI 图**，由 [Graph.cf](../grammar/Graph.cf) 定义

## λ 表达式

一个 λ 程序就是一个表达式。例如 `example.lambda` 可以是：

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个输入 `x`，输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 自身

因此整个表达式在规约后等价于：

```lambda
\y -> y
```

写法约定：

- 用 `\x -> 表达式` 定义单参数函数。多参数函数需要用到柯里化，比如 `\x -> \y -> x`
- 用 `f x` 表示函数应用，应用为左结合。例如 `f x y` 等价于 `(f x) y`
- 变量名以小写字母开头，后面可以接字母、数字或下划线
- 语法允许自由变量，但编译成 SKI 图的 λ 表达式不能包含自由变量。因为纯 SKI 图只有 `S`、`K`、`I` 和应用，只能表示闭合的 λ 表达式

### 丘奇编码

λ 表达式可以通过丘奇编码表示自然数，进而可以表示自然数的加法、乘法和幂。

项目的 λ 程序实现支持直接使用自然数和这些运算。语法为：

- 自然数表示为 `0`、`1`、`2`，要求是非负十进制整数
- 加法表示为 `a + b`，从左向右结合
- 乘法表示为 `a * b`，从左向右结合
- 幂表示为 `a ^ b`，从右向左结合

自然数和运算会被展开为纯 λ 表达式：

- `0` 展开为 `\f -> \x -> x`，`1` 展开为 `\f -> \x -> f x`，`2` 展开为 `\f -> \x -> f (f x)`，以此类推
- `a + b` 展开为 `(\m -> \n -> \f -> \x -> m f (n f x)) a b`
- `a * b` 展开为 `(\m -> \n -> \f -> m (n f)) a b`
- `a ^ b` 展开为 `(\m -> \n -> n m) a b`，因此 `0 ^ 0` 与丘奇数 `1` 等价

### 优先级顺序

解析优先级从高到低为：

1. 函数应用
2. 幂
3. 乘法
4. 加法
5. λ 抽象

因此

- `f 1 + 2` 等价于 `(f 1) + 2`
- `1 + 2 * 3 ^ 4` 等价于 `1 + (2 * (3 ^ 4))`
- `\x -> x + 1` 等价于 `\x -> (x + 1)`

## SKI 图

一个 SKI 图可以是一个 λ 程序的等价表示。例如 `example.ski` 与上述 `example.lambda` 等价：

```ski
#0 = #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. 约定 `#0` 为图的根节点
2. `#1 #2` 表示应用，`#1` 为函数，`#2` 为参数
2. `#0 = #1 #2;` 表示把应用的结果定义为根节点，或者理解为根节点的两条边分别连接到 `#1` 和 `#2` 节点
3. `#1 = I;` 和 `#2 = I;` 定义两个恒等组合子

因此整个图等价于

```ski
I I
```

归约的结果是

```ski
I
```

和此前的 λ 程序一致。

写法约定：

- 每个图文件必须定义根节点 `#0`。每个定义以分号结束
- 节点可以是 `S`、`K`、`I`，或 `函数节点 参数节点` 形式的应用
- 节点编号由 `#` 和十进制数字组成，按文本比较，因此 `#0` 与 `#00` 不同
- 编号不能重复，且每条边引用的节点必须已定义
- 语法本身允许环和不可达节点，是否接受由后续解释器的实现决定
