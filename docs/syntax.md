## 纯 λ

一个纯 λ 程序就是一个由变量、单参数抽象、函数应用组成表达式。

### 纯 λ 的示例

对于纯 λ

```lambda
(\x -> x) (\y -> y)
```

其含义为：

1. `\x -> x` 是一个单参数抽象，可视为输入 `x`、输出 `x` 的函数，即恒等函数
2. `\y -> y` 也是一个恒等函数
3. `(\x -> x) (\y -> y)` 表示 `\y -> y` 函数本身作为参数传递给 `\x -> x`，返回的结果就是 `\y -> y` 函数

整个表达式在归约后等价于

```lambda
\y -> y
```

### 纯 λ 的语法约定

- 用 `\x -> 表达式` 定义单参数函数。多参数函数需要使用嵌套抽象，比如 `\x -> \y -> x`
- 用 `f x` 表示函数应用。函数应用为左结合，优先于抽象。括号可改变结合顺序，因此 `f x y` 等价于 `(f x) y`
- 变量名以小写字母开头，后面可以接字母、数字或下划线
- 使用 `#` 开始行注释
- 解析器允许自由变量，但编译器会拒绝自由变量。因为纯 SKI 图只有 `S`、`K`、`I` 和应用，只能表示闭合的 λ 表达式

## 核心 λ

核心 λ 在纯 λ 的基础上扩展语法，提供定义、导入、导出、程序入口和标准库。

### 核心 λ 的语法约定

核心 λ 遵循[纯 λ 的语法约定](#纯-λ-的语法约定)，并有额外的语法约定。

关于定义：

- 使用 `name = 表达式;` 进行定义，每个定义最后都需要分号表示结束
- 定义的名称要求小写字母开头，后续可包含字母、数字或下划线；建议采用小驼峰命名法
- 同一文件中前面的定义可以引用后面的定义，但循环引用会报错
- 函数参数可以遮蔽同名的定义，即函数参数与定义重名时，函数体内的名称表示函数参数

关于导入和导出：

- 使用 `@> name = 表达式;` 定义并导出名称
- 使用 `@< "./relative.lambda" (name1, name2);` 根据相对路径从另一个文件中导入定义
- 同一文件可以导出多个定义
- 导入定义与本地定义重名时会报错

关于程序入口：

- 使用 `@! 表达式;` 作为程序入口
- 入口必须写在文件最后，一个程序只能有一个入口
- 只有包含入口的程序才可以被编译为 SKI 图

关于标准库：

- 标准库不需要显式导入，标准库的所有内置函数在所有程序中都可用
- 内置函数为大写字母开头，遵循大写蛇形命名法
- 内置函数是一等函数，可部分应用
- 内置函数遵循函数应用的结合顺序和优先级规则

标准库的详细说明见 [lib.md](lib.md)。

## SKI 图

一个 SKI 图可以是一个纯 λ 程序的等价表示。

### SKI 图的示例

对于 SKI 图

```ski
#0 = #1 #2;
#1 = I;
#2 = I;
```

其含义为：

1. 约定 `#0` 为图的根节点
2. `#1 #2` 表示应用，`#1` 为函数，`#2` 为参数
3. `#0 = #1 #2;` 表示把应用的结果定义为根节点，或者理解为根节点的两条边分别连接到 `#1` 和 `#2` 节点
4. `#1 = I;` 和 `#2 = I;` 定义两个恒等组合子

整个图等价于

```ski
I I
```

归约的结果是

```ski
I
```

和 λ 表达式 `(\x -> x) (\y -> y)` 的归约结果相同。

### SKI 图的语法约定

- 每个图文件必须定义根节点 `#0`。每个定义以分号结束
- 节点可以是 `S`、`K`、`I`，或 `函数节点 参数节点` 形式的应用
- 节点编号由 `#` 和十进制数字组成，按文本比较，因此 `#0` 与 `#00` 不同
- 编号不能重复，且每条边引用的节点必须在文件中定义。节点允许前向引用
- 使用 `--` 开始行注释
- 解析器允许环和不可达节点，但解释器会拒绝可达的环，并忽略不可达节点
