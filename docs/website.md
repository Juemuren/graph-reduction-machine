## 第三版：LSP（暂缓）

第三版在第二版的编辑器和虚拟文件基础上加入语言服务。

### 第三版预计路线

1. 验证语言服务器核心能否构建为 WASM
2. 复用已有模块中的分析逻辑
3. 把语言服务器接入第二版实现的编辑器。可以使用已有的成熟的 Web 编辑器 LSP 客户端

### 第三版功能范围

让浏览器中的核心 λ 和 SKI 图的编辑体验覆盖现有语言服务器的主要功能。

具体功能见 [语言服务器文档](lsp.md)。

多文件能力可能需要根据第二版的实现情况进行调整。

### 第三版验收条件

- 对核心 λ 和 SKI 图提供与现有语言服务器功能一致的语言服务。
- 重命名和签名提示等现有功能在适用语言中可用。
- 跨文件导入的悬停和跳转可定位到会话中的文件。
- 编辑器与现有命令行语言服务器对相同测试样例给出一致的关键结果。
- 长文件或频繁输入时页面保持可操作。

## 第四版：Benchmark（暂缓）

### 第四版暂缓原因

- 现有的 Python 比较脚本不能直接放到静态网站运行，需要用 TypeScript 或 JavaScript 重写
- 现有的比较图表和数据第一版已经实现了展示，因此在线 Benchmark 的重要性偏低

### 第四版预计路线

把现有的 Python 比较脚本的主要功能用 TypeScript 重写：

- 读取并解析 JSON 配置：Web 侧要使用相同的 JSON Schema
- 生成入口表达式、逐点测量、检查同一输入的结果是否一致：Web 侧按原有语义重新实现
- 子进程调用、磁盘读写、Matplotlib 绘图：Web 侧要改用 Playground 的运行接口、浏览器下载、JavaScript 绘图库
